# 닥터다이어리 메인 · 3차 재현 평가

날짜2026-09-10. 사용자 요청은 디맨드 긍정 평가 후 닥터다이어리 메인으로 같은 실험을 이어가는 것이다. [P1](../../design/reference-language/round-03/prompt-v1.md)을 구현 전에 고정했다. 원본1125×2436에서 OS 영역을 제외한 y170–2436을 선택했고390 CSS px 비교를 사용했다. 원본 CSS/DPR는 미상이다.

## 평가 표면

분석자와 별도 리뷰어는 원본을 직접 봤다. 구현 담당은 P1~P4와 광고/고유그림 crop·공식SVG만 받았다. 원본을 열지 않았다고 각 버전에서 보고했다. 같은 담당의 연속 수정이므로 네 번의 새로운 독립 재현 표본으로 세지 않는다. 배너의 내부 카피와 그림은 기존 합성 에셋이고 언어로 생성한 성과에 포함하지 않는다.

## 실제 실패와 교정

P1은 E6 날짜 잉크와 행 박스를 혼동해 기록을 약14px 아래에 놓았고, 선행5의 위치가 오른쪽끝에 붙어 FAB로 전부 가려졌다. P2는 날짜top/linebox/기록경계와 값의 부분노출을 각각 명시했다. 정지 원본에서 보이지 않는 숫자는 만들지 않았다.

독립표본의 공유 계약을 E1으로 세는 배열 오류는 자체 구현 중 수정됐고 reviewer가 이전 snapshot을 보존했다. 넓은 부모 안320표본의 조건은 컨테이너로 검사했다. P3는 미사용/직접값 토큰과 기록 목록 의미구조를 보강했다. P2→P3는390/320렌더의 변경 픽셀0으로 시각 유지 여부를 별도 확인했다.

같은폭 전체비교에서 E4 작은그림까지36px로통일한 차이가 발견됐다. P4는 배치슬롯36을공유하면서crop별표시크기를구별하고행간격8→16/아래18→10으로 전체192px안의둘째행을8px내렸다. flag표시크기도crop비율로맞췄다. 이교정은입력단순화실패를수정한것이며새공통수치를만들지않는다.

## 재사용 여부

기존 스킬의 잉크/박스·가림·실제 가용폭·토큰 참조 원리를 이번 사례에 적용했다. 스킬 본문 변경 없이 실제 실패/교정과 AE 회귀 사례를 추가한다. 같은 슬롯과 다른 그림 크기의 구별은 후속 평가 대상으로 보존한다. 한 사례의 교정 성공을 새로운 지침의 범용 개선이나5회 이상 독립 표본 검증으로 확대하지 않는다.

## 증거와 한계

[비교/교정](../../design/reference-language/round-03/review.md), [보드](../../design/reference-language/round-03/index.html), [게이트 판독](../../design/reference-language/round-03/gate-review.md)에 Q/E/F-ID와 실제 결과를 연결한다. 앱390/320와 독립표본의 geometry/가림/글자/이미지/정적범위를 검사한다. 보드1100/390/320에서8개프롬프트펼침닫힘,키보드,고대비포커스,이미지/링크/가로넘침을검사했다. HTML/CSS앱에는새JS가없고검증JS는기존oxlint와checkJs를별도실행한다.

역사 게이트는 알려진 실패와 당시 미검증을 유지한다. 최종 결과는 현재소스해시와 [gate-result](../../design/reference-language/round-03/gate-result.json)에 연결한다. 서비스 이동·기록추가·광고실행·실물휴대폰/Safari는 미검증이다. 닥터다이어리에 대한 사용자 품질 평가는 아직 대기다.
