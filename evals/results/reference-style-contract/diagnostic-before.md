# 변경 전 진단 적용 — 독립 대조 표본 아님

## 유효성 경계

평가 담당은 raw R1/R2/R3/R5와 동결된 기존 스킬을 직접 읽었다. 그러나 슬롯 조사 `list_agents`가 완료된 round4_review의 최종 답을 자동 반환하여, 이 답을 작성하기 전에 거절 UI의 차이와 가능한 커스텀 팔레트 제안에 노출되었다. 따라서 아래는 진단 적용이며 control/fresh-context 표본 또는 baseline 실패 증거로 계수하지 않는다. 수정 후 스킬은 아직 읽지 않았다. 실제 구현과 이미지 품질 평가도 아니다.

## 구현 전 분석

범위: 반려동물과 갈 카페를 검색하고 동반 조건을 확인해 선택하는 모바일 탐색 화면. 원본은 R1 946×2048, R2 666×1440, R3/R5 946×2048 image-px이며 CSS viewport/DPR는 미확인이다. 390 CSS px 화면을 이번 구현 선택으로 둔다.

- R1/O1: 검색과 지역, 넓은 프로모션 이미지, 짧은 카테고리 묶음의 순서다. 검색을 바로 발견한 뒤 목적을 정하지 않은 사용자도 그림으로 탐색할 수 있다. 로고와 이벤트 내용은 제품 정보로 채택하지 않는다. 배너 크기와 퀵메뉴가 전체 첫 화면의 비중을 크게 차지한다는 관찰을 유지한다.
- R2/O2: 사진이 왼쪽, 이름·설명·평점·조건이 오른쪽이고 가능 시간이 정보 아래에 모인다. 매장 내부 정보보다 매장 사이의 간격이 크다. 카페 각색에서는 메뉴 장문보다 실내 동반·크기 제한·목줄 조건을 매장 판단 정보로 대체한다. 실제 예약 기능이 확인되지 않아 시간 버튼을 새로 넣지 않는다.
- R3/O3: 사진 두 열이 비슷한 폭을 가지며 이미지 다음 이름과 작은 조건, 굵은 가격 순으로 읽힌다. 탐색 홈의 테마 묶음에만 적용하고 조건을 자세히 비교하는 결과 목록은 R2 행 구조를 쓴다.
- R5/O5: 날짜·인원·시간이 하나의 선택면에서 이어지고 선택한 값은 채움면으로 구분된다. 이번 범위는 방문 날짜 선택까지다. 반려동물 수/몸무게와 인원은 서로 다른 조건이므로 별도 입력을 신규 결정한다.

Q1: R1의 검색→지역→이미지 탐색→짧은 목적 묶음을 홈 위계에 연결한다. Q2: R2의 사진/정보 병렬, 내부보다 큰 항목 사이 간격을 결과 행으로 연결한다. Q3: R3의 동일 폭 사진과 반복되는 정보 순서를 테마 탐색에 연결한다. Q5: R5의 현재 선택과 대안의 구분을 방문일 선택면에 연결한다. 네 Q 모두 렌더 전 unverified다.

## 실행 프롬프트

390 CSS px 모바일 카페 탐색 시안의 홈 한 화면을 구현한다. 기본 화면 패딩은 20px이며 화면 컨테이너가 소유한다. 먼저 `카페 찾기` 제목과 `지역이나 카페 이름 검색` 입력, 선택 지역과 `동반 조건` 버튼을 둔다. 이미지 탐색 영역은 하나의 실제 카페 사진을 크게 쓰되, 검색과 조건 선택이 먼저 읽히게 한다. 아래에는 `실내 동반`, `넓은 야외`, `대형견 동반` 목적을 짧은 그림/라벨 묶음으로 둔다. 검증된 에셋이 없으면 임의 그림을 만들지 말고 에셋 필요 상태를 표시한다.

검색 결과는 왼쪽 사진과 오른쪽 카페명·지역·동반 조건을 같은 행에 조립하고, 사진은 정보 블록 높이와 함께 읽히도록 한다. 이름은 18px/700, 조건은 14px/400, 줄높이는 각각 26/21px로 선택한다. 매장 내부 gap 8px, 매장 사이 28px는 chosen 값이며 내용 길이에 따라 행 높이는 늘어난다. 조건은 실제 확인 여부를 표시하고 unknown 정보를 가능으로 바꾸지 않는다. 사진·본문 아래 상세 진입 버튼을 그 매장에 소속시킨다.

색·표면은 원본에서 관찰되는 검색의 낮은 강조, 중요한 정보의 강한 글자 대비, 선택/실행 조작의 구별을 유지하도록 선택한다. 이번 팔레트는 아직 확정하지 않는다. 원본의 오렌지 색상명만 전달하지 말고 실제 팔레트를 확정한 뒤 구현 입력 버전을 고정한다. 검색과 조건 선택, 상세 진입, 날짜 선택은 신규 행동이며 원본 정지 이미지에서 확인한 동작으로 적지 않는다. 선으로 영역을 나누거나 탭 밑줄을 만들지 않는다. 첫 렌더에서 Q1/Q2의 정보 비중과 묶음 간격을 같은 표시 폭의 원본과 대조한 뒤 확장한다.

## 자기 판독

동결 스킬의 O/D/Q 분리와 요소 관계는 적용됐지만 팔레트 결정은 열린 상태여서 이 입력은 곧바로 완결된 스타일 구현을 보장하지 않는다. R1의 이미지/그림/조작부가 만드는 화면 수준 표현을 수치와 에셋 선택까지 연결하는 계약은 충분하지 않다. 이 평가는 외부 리뷰 텍스트 노출 후 작성되었으므로 자연발생 누락/실패율로 쓰지 않는다.
