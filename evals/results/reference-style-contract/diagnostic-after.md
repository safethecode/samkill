# 변경 후 적용 진단과 반례

## 평가 경계

같은 평가 담당이 변경 전 동결 스킬과 변경 후 세 파일을 읽은 후 작성했다. 리뷰 텍스트에 노출되었고 독립 fresh 표본이 아니다. 아래는 문구의 적용 가능성과 조건 경계를 직접 판독한 결과이며 5회 행동 평가 또는 실제 UI 검증 PASS가 아니다. 변경의 실증 baseline은 별도로 보존된 사용자 거절/P1–P3이며 이 파일이 baseline을 대신하지 않는다.

## 현실 과제에 적용한 스타일 계약

**범위:** R1을 주 기준, R2/R3/R5를 보조로 반려동물 동반 카페 탐색 화면을 각색한다. 관찰은 앞서 직접 본 raw 이미지에 한정한다.

| 관찰 | 효과/가설 | 유지할 관계 | 제품 결정과 실행 매핑 | 비교 |
|---|---|---|---|---|
| R1의 바탕은 넓고 밝다. 검색은 저채도 면, 그림·큰 배너에는 여러 색이 있다. | 조작부가 그림의 풍부함과 경쟁하지 않으면서 탐색 구역이 눈에 들어온다는 가설 | 검색의 중립면 ↔ 그림의 시각적 풍부함 | 검색 surface-muted, 카테고리는 검증된 다색 그림 자산. 배너는 필요 없는 광고 대신 사용자 과제에 맞는 장소 탐색 영역을 검토 | 첫 화면의 시선 순서/면적 unverified |
| R2의 매장명은 굵고 어둡고 부가정보는 더 밝다. 가능 시간은 넓은 채움 버튼이다. | 이름으로 후보를 구별한 뒤 행동을 찾기 쉽다는 가설 | 제목/설명 대비와 정보/행동 대비 | 이름 text-primary, 동반 조건 text-secondary. 예약을 제공하지 않으므로 시간 버튼은 복제하지 않고 상세 진입을 각 매장 행동으로 둔다 | 정보보다 버튼이 과도하게 먼저 보이는지 unverified |
| R2는 행 내부 사진·정보가 가깝고 다음 매장과는 크게 떨어져 있다. | 한 매장의 조건과 행동을 같은 단위로 묶는다는 가설 | 내부 gap보다 큰 항목 간 gap | item-inner 8px, item-gap 28px chosen; 긴 조건은 높이가 늘어나도 다음 매장 gap을 유지 | 좁은 폭/긴 조건 unverified |
| R3 사진 두 열은 표현이 풍부하고 그 아래 정보 순서가 반복된다. | 카페 분위기를 빠르게 비교할 수 있다는 가설 | 사진의 반복 비율과 이름/조건 순서 | 테마 탐색은 두 열, 상세 조건이 필요한 검색 결과는 R2 행을 사용; 사진 색을 컨트롤 배경으로 확장하지 않는다 | 전체 일관성 unverified |
| R5의 선택 날짜와 인원에는 강한 채움이 있고 대안은 가볍다. | 선택값을 재확인하기 쉽다는 가설 | 선택과 대안의 강도 차이 | 방문일 선택에만 적용. 인원·반려동물 조건은 의미를 구별한 신규 입력 | 실제 선택/포커스 unverified |

**실행 프롬프트:** 390 CSS px에서 검색→지역/동반 조건→목적별 탐색→카페 후보 순으로 조립한다. 화면 기본 padding 20px는 화면 컨테이너가 소유한다. 원본 CSS 수치로 주장하지 않는다. 첫 후보를 읽고 동반 조건을 판단할 수 있는 비중을 확보한다. 화면 바탕은 #FFFFFF, 검색 면 #F3F4F6, 제목 #171717, 부가정보 #555555, 행동/선택은 #7C3AED를 chosen으로 둔다. 이 색은 원본 브랜드의 복제값이 아니며 밝은 바탕에서 행동을 구별하는 역할을 옮긴 가설이다. 행동색은 상세 진입과 현재 선택에만 집중하고 검색·모든 필터를 같은 강도로 채우지 않는다. 카테고리 그림은 원본에서 관찰한 형태/채움의 풍부함을 유지할 검증된 자산을 명시적으로 전달한다. 에셋이 없으면 작은 윤곽 아이콘으로 자동 축소하지 말고 입력 미완료로 남긴다. 테마 사진 색은 사진 안에 둔다. 요소 내부 8px, 매장 사이 28px chosen을 쓰고 이름 18/26px 700, 조건 14/21px 400으로 한다. 카페명·동반 조건 길이가 늘면 높이를 확장한다. 표면·그림·강조 면적과 그룹 경계를 전체 화면에서 원본과 같은 표시 폭으로 비교한 뒤 개별 요소를 확인한다. 아직 실제 렌더가 없으므로 스타일 유지·개선 판정은 모두 unverified다.

**판독:** 추가 계약은 전역 표현 관찰과 구현 역할 매핑을 기존 요소 계약 앞에 놓을 수 있다. 관찰 사실과 효과 가설을 구분한다. 특정 색상의 복사나 특정 커스텀 팔레트에 합격을 종속하지 않는다. chosen 팔레트의 실제 품질과 대비는 별도 렌더/검사 대상이다.

## 반례 1: 정확한 복제

과제: “R2를 가능한 한 똑같이 정적으로 재현해 줘. 색은 바꾸지 마.”

적용 답: R2의 관찰된 오렌지 계열 강조색과 흰 바탕·중립 글자 대비를 유지한다. 이미지에서 색을 표본 추출하면 이미지 표본값으로 기록하고 원본 CSS라고 단정하지 않는다. 새 브랜드색을 제안하지 않는다. 기존 사용자 제약과 충돌하는 탭/영역 구분선 등이 있다면 원본 관찰은 남기고 그 한정된 차이를 별도 기록한다. 원본 자체의 정확한 재현과 제약 때문에 각색된 부분을 같은 판정으로 묶지 않는다.

판독: “색 변경이 없는 정확한 재현 요청” 조건이 직접 매치한다. 각색용 색 변경 가이드를 강제할 이유가 없다. 실제 복제 정확도는 미검증이다.

## 반례 2: 무채색 레퍼런스

과제: “제공한 무채색 카페 목록의 차분함을 유지해 우리 앱에 적용해 줘.” 이 반례에는 별도 raw 이미지가 제공되지 않았다.

적용 답: 이미지가 없으므로 실제 원본의 대비·면적을 관찰했다고 쓰지 않는다. 이미지를 직접 확인한 뒤 무채색 안의 명도·글자 굵기·면적·선택면이 어떤 순서와 그룹을 만드는지 계약한다. 선택 상태를 구별하는 데 검정 채움/흰 글자와 미선택 중립면이 충분하면 채도 높은 새 색을 넣지 않는다. 대비가 부족한 구역만 그 역할에 맞게 조정하며 무채색 전체를 결함으로 판정하지 않는다.

판독: 새 규칙이 고채도 팔레트를 보편 요구로 만들지 않는다는 적용 경계는 명료하다. raw 무채색 이미지가 없으므로 관찰 기반 반례 행동 평가는 NOT RUN이며 문구 진단만 했다.

## 반례 3: 광고가 필요 없는 제품

과제: “이 카페 찾기 도구에는 광고·프로모션이 없어. 검색과 조건 비교가 핵심이야.”

적용 답: R1의 큰 프로모션과 동일 면적의 광고·장식 배너를 새로 만들지 않는다. 제거 후 지역/동반 조건과 후보의 상대 비중을 다시 정한다. R1에서 유지할 것은 중립 검색의 발견성, 목적별 탐색의 구분, 그림과 조작의 표현 차이이며 광고 좌표 자체가 아니다. 공간을 후보에 돌렸다면 R2식 그룹 간격으로 매장 경계를 유지하고 과도한 밀도 증가가 없는지 첫 화면에서 확인한다.

판독: 원본의 모든 면적을 무조건 보존하는 과잉 일반화를 막는 조건이 있다. 원본처럼 광고 면적을 채웠는지는 합격 기준이 아니다. 재배분 결과는 렌더 전 unverified다.

## 결론과 남은 검증

조건별 읽기에서 exact-copy·무채색·광고미필요 범위를 보존할 수 있었다. 실제 fresh control/updated 행동 표본은 0/10이고 새 문구가 반복 출력의 실패율/분산을 줄였다는 결론은 낼 수 없다. 사용자가 거절한 구체 실패를 보존하고 계약을 보강했다는 변경 이유와, 독립 행동 효과가 아직 검증되지 않았다는 한계를 함께 유지해야 한다.
