# 한국어 UI 문구 명세

가상 제품의 제공 사실만 사용했다. `ux-copy/SKILL.md`, `copy-contract.md`, `korean-writing.md`를 적용했다. 아래 ID는 예정 문자열 key다. UI 문구와 구현 조건을 분리했다.

| ID | 위치 | 최종 UI 문구 | 연결 행동 | 상태 |
|---|---|---|---|---|
| C1.title | 설문 안내 제목 | 배송 선호 설문에 참여해 보세요 (선택·3문항) | 없음 | ready |
| C1.start | 주요 버튼 | 배송 설문 시작하기 | 배송 선호 설문 열기 | ready |
| C1.skip | 보조 버튼 | 건너뛰기 | 설문 없이 다음 단계로 이동; 목적지 확인 필요 | draft-dependent |
| C2.title | 갱신 취소 제목 | 자동 갱신을 취소했어요 | 없음 | ready |
| C2.body | 설명 | 12월 12일까지 이용할 수 있어요. 더 이상 요금이 청구되지 않아요. | 없음 | ready |
| C3.title | 결제 확인 제목 | 유료 이용을 시작할까요? | 없음 | ready |
| C3.body | 설명 | 지금 7,900원이 결제돼요. 이후 매월 7,900원이 결제돼요. | 없음 | ready |
| C3.confirm | 결제 버튼 | 7,900원 결제하기 | 즉시 7,900원 결제 및 월 결제 시작 | ready |
| C3.exit | 보조 버튼 | 나가기 | 결제하지 않고 화면 닫기; 연결 확인 필요 | draft-dependent |
| C4.message | 삭제 요청 접수 | 계정 삭제 요청을 받았어요. 요청 접수 후 7일 이내에 계정이 삭제돼요. | 없음 | ready |
| C5.message | 전액 상환 완료 | 대출을 모두 갚았어요. 축하해요! | 없음 | ready |
| C6.message | 검색 조건 안내 | 검색 조건에 따라 결과가 없을 수 있어요. | 없음 | ready |

## 노출 조건·근거·검증 계약

- **C1:** 배송 선호를 묻는 선택 설문 진입 전 노출. 질문 수는 3개이며 보상은 미확정이다. ‘보상을 받으세요’를 실제 직후 행동으로 교체했다. 건너뛰기 목적지는 unknown이므로 연결 전 활성화하지 않는다. 제목은 설문 전체가 선택임을 뜻한다. 버튼과 질문 수·선택 여부가 제공 사실과 일치하는지 검토했다.
- **C2:** 유료 플랜의 자동 갱신 취소가 확인된 때 노출. 이용 종료일은 12월 12일, 추가 청구는 없다. ‘플랜 캔슬’, ‘성공적으로 처리’, ‘정상 완료’를 제거하고 바뀐 상태를 썼다. 제목의 취소 사실을 설명에서 반복하지 않고 이용 기간과 청구 여부를 보존했다.
- **C3:** 즉시 결제 직전 노출. 즉시 7,900원 및 이후 매월 7,900원이라는 제공 조건을 모두 표시했다. 무료 체험은 사실과 맞지 않으며, 거절을 ‘혜택 포기’로 표현하지 않았다. 나가기의 미결제 종료 동작은 구현 조건이며 아직 확인하지 않았다.
- **C4:** 삭제 요청 접수가 확인됐고 삭제 자체는 아직 완료되지 않았을 때 노출. 확정 정책인 접수 후 7일 이내를 유지했다. ‘삭제했어요’나 ‘7일 후 삭제돼요’로 바꾸지 않았다.
- **C5:** 대출 전액 상환 확인 후에만 노출. 짧은 축하만 더했으며 노력·기간·보상·신용 변화는 추정하지 않았다.
- **C6:** 필터에 따라 결과가 없을 가능성을 안내할 때 노출. 실제 0건 확정 문구가 아니다. 명사화·피동을 덜고 ‘없을 수 있어요’의 가능성을 보존했다.

텍스트 사실 대조를 수행했다. 8원칙 적용: ① C1·C3 버튼은 직후 행동을 예고하고, ② C2의 완료 수식을 덜고, ③ 제목과 설명의 반복을 없앴다. ④ C3 비용·주기와 C2 기한을 남기고, ⑤ C6을 말하기 쉬운 문장으로 고쳤다. ⑥ C1 건너뛰기·C3 나가기로 선택을 존중하고, ⑦ C2 ‘캔슬’을 쉬운 말로 바꾸고, ⑧ C5에만 상황에 맞는 축하를 더했다. 실제 화면·브라우저·음성 테스트는 수행하지 않았다. 좁은 폭, 줄바꿈, 긴 변수, 스크린리더 이름, 실제 상태·행동 연결은 **not-verified**다.
