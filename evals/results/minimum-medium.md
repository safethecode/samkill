# 최소 medium 굵기 회귀 평가

## 요구

2026-09-22 사용자 교정: 텍스트를 무조건 medium으로 통일하는 것이 아니라 최솟값을 medium(500)으로 적용한다. 600/700 강조는 보존한다.

## 기준 전 독립 표본

기존 기준인 14px 하한·토큰화·위계 유지와 본문/보조 400, 버튼 500, 제목 700인 레퍼런스를 주고 CSS를 요청했다. 독립 에이전트는 body, muted-help, input, input::placeholder에 regular(400), button에 500, h1/h2에 700을 선택했다. 기존 지침에는 굵기 하한이 없어 새 요구의 본문·입력 하한을 보장하지 못했다. 과거 명세 위반으로 소급 판정하지 않는다.

## 회귀 입력과 기대 결과

| 입력 | 기대 |
| --- | --- |
| 본문·도움말 400, 버튼 500, 제목 700 | 본문·도움말 500, 버튼 500, 제목 700 |
| 모든 텍스트를 500으로 일괄 치환 | 거절: 제목·강조 위계 보존 |
| placeholder·비활성 라벨만 400 | 500 이상으로 수정, 대비 별도 확인 |
| medium 토큰 실제 값 400 또는 가변 축 450 | 실패: 이름이 아니라 실제 값 검사 |
| 제공 로고 이미지·아이콘 폰트 | 임의 변형 금지 |

## 기준 후 독립 표본

새 맥락의 독립 에이전트에 새 규칙과 위 입력을 제공했다. body·도움말·input·placeholder·button은 500, heading은 700을 선택했다. 일괄 500, 비활성 400, medium 토큰의 실제 값 400/450을 모두 실패로 판정했고 아이콘 굵기 변경은 범위 밖으로 구별했다. 굵기 준수와 대비 준수도 구별했다. 다섯 시나리오의 기대 결과와 일치했다.

기준 전후 각 1개 표본의 문서 행동 검증이다. 반복 실험이나 기존 제품 화면의 일괄 수정·렌더 검증을 의미하지 않는다.
