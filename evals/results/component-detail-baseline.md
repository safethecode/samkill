레퍼런스 CTA 구현 인계

R1은 사용자 제공 관찰문이에요. 이미지를 직접 확인하지 않았으므로 확인 상태는 `not-inspected`예요. 앱·자료 경로·수집 시점은 unknown이에요. 프리뷰는 600×1200 래스터이며 원본 크기, CSS 뷰포트, 기기 배율은 unknown이에요. 주 레퍼런스는 R1만 사용해요.

과제는 CTA의 외형을 구현팀에 전달하는 것이에요. 실제 행동, 대상 플랫폼, 브랜드·기존 토큰은 unknown이에요.

| 관찰 | 사용자 제공 근거 |
|---|---|
| O1 | 파란색 둥근 CTA에 흰색 라벨이 있어요. 정확한 색상·반경은 unknown이에요. |
| O2 | 화살표는 흰색 윤곽선이며 선 끝이 둥글어요. SVG 구조·선 두께는 unknown이에요. |
| O3 | 테두리에서 보이는 콘텐츠까지 가로 거리는 약 24 프리뷰 px, 아이콘과 라벨 간격은 약 8 프리뷰 px예요. 사용자 시각 추정이며 측정 방법은 미상이에요. |
| O4 | 보이는 라벨 글리프 높이는 약 14 프리뷰 px예요. 글꼴·font-size·line-height는 unknown이에요. |

해석: 배경과 라벨의 색 대비로 주요 행동을 강조하는 형태로 보여요. 실제 가독성·효과는 미검증이에요.

| 결정 | 적용 규칙·값 | 구현 대상·검증 |
|---|---|---|
| D1 / O1 | 파란 배경·흰 라벨·둥근 외곽을 보존해요. 정확한 색상과 반경은 기존 토큰 확인 후 정해요. | CTAButton(예정), 동일 표시 배율에서 비교해요. |
| D2 / O2 | 흰 윤곽선 화살표와 둥근 선 끝을 채택해요. 두께·크기·join은 미정이에요. | CTAIcon(예정), 선 끝과 윤곽을 비교해요. |
| D3 / O3–O4 | 가로 padding·gap·font-size의 CSS 값은 미정이에요. 프리뷰 24/8/14px를 그대로 CSS에 옮기지 않아요. | 콘텐츠 경계와 글리프 경계가 박스 경계와 다를 수 있어 원본 배율·DOM 확인 후 확정해요. |

배제: 근거 없는 그림자·그라데이션은 추가하지 않아요. 현재 관찰문에서 확인되지 않았기 때문이에요. 의도적인 외형 변경은 없어요.

미확인: 세로 패딩, 버튼·아이콘 크기, 글자 굵기, hover/focus/disabled/loading 및 클릭 동작이에요. 상태별 명세는 별도로 정해야 해요. 관찰문 밖 요소의 부재를 단정하지 않아요.
