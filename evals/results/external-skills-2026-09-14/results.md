# 외부 스킬 보완 평가

날짜: 2026-09-14. 입력·출처는 [분석 대응표](../../../docs/external-skills-analysis.md), 고정 revision과 파일 해시는 [inventory](source-inventory.json)에 있다.

## 평가 방식

수정 전 독립 에이전트에는 기존 스킬과 AV–AZ의 요청 5개만 전달했다. 수정 후에는 새 독립 에이전트에 동일 5개 요청, AY/AZ의 반례, BA의 효과 설명·밀도 대안 요청을 전달했다. 서로의 답이나 기대 판정을 전달하지 않았다. 모든 응답은 spec-only이며 외부 스킬 본문은 평가 에이전트에 제공하지 않았다. 독립 리뷰 담당은 외부 원본과 변경 지침을 직접 대조한다.

평가 질문의 요청 사실은 [사례 AV–BA](../../cases.md)에 보존한다. 채점은 사실·범위·검증 근거와 구체 행동을 기준으로 하며 같은 문구를 썼는지 세지 않는다.

## 수정 전

[baseline](baseline.md)에서 5개 모두 기대를 충족했다. 기존 지침의 실패를 만들지 않았으므로 이번 변경의 인과 효과나 정확도 상승을 주장하지 않는다. 보완 목적은 재사용할 상세 검증 방법과 변경 귀속 기록을 찾기 쉽게 연결하는 것이다.

## 수정 후 및 문서 검증

독립 적용·리뷰·형식·링크·공백 검증의 최종 결과를 아래에 누적한다. 실제 제품 UI·동작의 게이트 PASS와는 별개다.

[수정 후 적용](updated.md): 동일 5개 요청과 4개 반례, BA의 효과 설명·대안 선택에서 사실/범위/기존 금지 보존을 확인했다. 폰트·합성 배경·전이·변경 귀속의 상세 참고 문서를 실제 답변에 적용했다. 새 실패는 관찰하지 못했다.

독립 `review_skill_changes`는 신규 문서와 외부 원본·기존 규칙을 대조해 내용상 수정할 명백한 결함을 발견하지 못했다. 중간 시점의 링크 검사에서 아직 작성하지 않은 results.md 1개를 보고했으며 이 파일을 작성해 해소한다. 원본 inventory 65개 SHA-256 일치와 당시 diff 공백 검사를 확인했다. 최종 루트 맥락/링크 검사는 별도 수행한다.

최종 정적 결과는 [validation.json](validation.json)에 기록한다. 전체 스킬7개에 skill-creator의 quick_validate를 실행해 통과했다. 첫 실행의 시스템Python PyYAML 부재는 임시 `/tmp/samkill-skill-validation-20260914` venv에서 해결했다. 저장소 의존성은 바꾸지 않았다. 변경 Markdown의 로컬 파일/앵커, 신규 파일 공백, git diff --check와 catalog/판독기의 HEAD 대비 바이트 불변을 검사한다. 판독기를 바꾸지 않아 Python 단위 테스트는 실행하지 않았다.

## 범위와 한계

아이콘·레이아웃 상세 후속은 [별도 평가](icon-layout.md)에 이어 기록한다. 앞선 독립 리뷰가 발견하지 못했던 후행 기본 규칙의 문서 모순을 수정했고, 신규 상세 기준을 BB–BF로 평가했다. 앞선 검사 결과는 당시 파일 상태의 기록으로 보존한다.

- 제품 소스, catalog의 75개 규칙/버전, Python 판독기는 변경하지 않는다.
- scanner를 복사·설치·실행하지 않으므로 그 테스트나 한국어 탐지 정확도를 통과했다고 하지 않는다.
- 스킬 입력의 독립 전후 적용은 각 1회다. 5개 시나리오는 5회 독립 반복이 아니다. 5회 이상 반복 실험·범용 행동 개선은 미검증이다.
- 실제 제품 렌더·서버 상태·스크린리더 낭독·모바일 기기 시험은 이 스킬 문서 보완의 실행 결과가 아니다. 해당 제품에서 새 기준을 사용할 때 검증한다.
- 커밋·푸시·배포·개인 연결 변경은 수행하지 않는다.
