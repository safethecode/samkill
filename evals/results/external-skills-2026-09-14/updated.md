# 수정 후 독립 적용

2026-09-14, 새 독립 에이전트 `updated_eval`. 기존 평가 응답·기대 판정을 제공하지 않고 수정된 관리 원본으로 동일 요청 5개, 반례 4개와 BA 요청 2개를 spec-only 수행했다. 다음은 실제 응답의 요약/발췌이며 제품 실행 증거가 아니다.

| 사례 | 실제 결과 | 판독 |
|---|---|---|
| AV | 서버 저장 후 응답 유실, 클릭/Enter/submit, 요청 A/B 역전, 필터 이동 후 복구, 실제 낭독을 시험 표로 작성 | 조건·데이터·화면 전이를 연결. 실제 실행은 미검증 |
| AW | “비활성 UI 예외는 보조 본문에 적용하지 않습니다.” 전경·부모 opacity·사진 크롭·테마/폭·기준 기록 | 역할 분리와 합성 대비 구체화. 캡처 부재도 명시 |
| AX | 실제 320 viewport와 형제 압축 컨테이너를 구별. 폰트 미로드/지연/완료, 실제 fallback·굵기, 간격 확대 | 표본 폭/실제 환경을 구별. 14px 하한과 실기기 한계 유지 |
| AY | 수사만 제거, 40%·20명·내부 실험·기존판·조건 유지·재검색 가능성 보존 | 의미 보존. 단축 지표/실험 검증을 별도 미확인 |
| AZ | introduced/regression/pre-existing/origin-unverified와 현재 fail/unknown 구별. 공통 원인은 한 V-ID+소비 화면 | 발생 시점 미확인을 현재 재현 결함의 해제로 사용하지 않음 |
| BA 효과 | 정확한 CSS/라이브러리 복원 불가. 층 구성은 가능한 가설로 제안 | 정지 이미지의 근거 한계 유지 |
| BA 대안 | 같은 내용·브랜드·기능에서 밀도 A/B, 비교 과제를 가정해 B 선택. 비용·Q-ID 미검증 표시 | 위임에 따라 방향 제시. 실제 밀도 우열을 확정하지 않음 |

반례 결과: 달력의 균일 gap, 기존 브랜드 serif, 실제 순서 01/02는 해당 기능/브랜드 근거로 유지하되 기존 규칙을 대조한다. aria-label→aria-labelledby는 ID 존재·고유성·이름과 낭독의 동등성을 확인한 뒤 판정한다. 속성 삭제만으로 회귀를 만들지 않는다.

수정 전 5개도 같은 핵심 판단에 도달했다. 추가로 응답에 나타난 구체 항목은 새 참고 문서의 사용 가능성을 보여주지만 성능 향상이나 범용 인과 효과를 증명하지 않는다. BA/추가 반례에는 수정 전 동일 평가가 없다.

사용 문서: state-stress, change-review, typography, design-tokens, reference-synthesis, product-reasoning, deslop-triage와 각 진입 스킬·기존 review/copy/gate 계약. 별도 제품 파일·외부 저장소·실제 렌더는 사용하지 않았다.
