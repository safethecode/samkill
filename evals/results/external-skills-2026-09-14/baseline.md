# 수정 전 독립 적용

2026-09-14, 독립 에이전트 `baseline_eval`. 수정 전 관리 원본을 읽고 파일 변경 없이 5개 요청을 spec-only로 수행했다. 외부 스킬과 부모의 개선안을 전달하지 않았다. 아래는 실제 응답의 짧은 발췌와 판독이며 전체 원문을 복제하지 않는다.

| 사례 | 실제 응답 발췌 | 판독 |
|---|---|---|
| AV 저장 복구 | “재시도 성공만으로 복구를 통과시키지 않는다.” “서버 저장 전 실패와 서버 저장 후 응답 유실을 구별해 재현한다.” | 입력·중복·응답 역전·안내 보존을 구체화. spec-only 범위 유지 |
| AW 사진 대비 | “secondary → disabled 경계 참조는 서로 다른 역할의 결합이라는 검토 대상이다.” | 합성 배경·크롭·테마와 캡처의 제한을 구별. PASS 거절 |
| AX 말줄임 | “hover만으로 전체 제목을 확인하게 하는 방식은 터치와 키보드의 해결책이 아니다.” | 전체 값 접근, 폰트 미로드/지연/완료, 320px·확대·복귀 명세 제공 |
| AY 문구 | “검색 40% 단축(내부 실험, 20명, 기존판 대비).” | 수치·조건·가능성 유지. 단축 대상을 시간으로 발명하지 않음 |
| AZ 변경 | “이번 변경이 만들지 않았다는 사실이 현재 제품 게이트에서 그 결함을 통과시킬 이유는 아니다.” | 전후 귀속·현재 실패 보존·소비 화면 검증을 구별 |

문구 실제 결과: “검색해 보세요. 검색 40% 단축(내부 실험, 20명, 기존판 대비). 검색에 실패해도 조건을 그대로 두고 다시 검색할 수 있어요.” 원문 사실을 보존했고 실험의 진위·레이아웃·동작을 검증했다고 하지 않았다.

사용 파일 보고: AGENTS.md, DESIGN.md, 최근 session-context, reference-to-ui/reference-review/ux-copy의 SKILL.md 및 design-tokens/ui-composition/mobile/review-criteria/design-gate/feedback-regression/failure-catalog/copy-contract/korean-writing.

실패가 관찰되지 않았다. 따라서 이번 보완을 이 5개 문제의 신규 해결이나 RED→GREEN 효과로 주장하지 않는다. 외부 분석에서 확인한 구체 검증 방법을 기존 기준의 참고 문서로 통합하고 수정 후에도 판단이 퇴보하지 않는지 본다. 표본 수 1, 실제 제품 렌더·서버·보조 기술 시험은 수행하지 않았다.
