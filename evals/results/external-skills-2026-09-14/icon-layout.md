# 아이콘·레이아웃 후속 평가

2026-09-14. 앞선 자료의 미확인 범위였던 Jakub `icons.md`, `icon-transitions.md`, `hit-areas.md`, `grouping-and-alignment.md`, `spacing-and-adaptivity.md`를 동일 고정 revision에서 전문 대조했다. 원본 해시는 기존 source-inventory에 있다.

## 실제 문서 결함

수정 전 `design-tokens.md`에는 “기본 순서는 label → icon”이 남아 있었다. AGENTS/ui-composition의 역할·관례 중심 기준과 모순이다. 사용자의 아이콘 반영 여부 질문에서 발견했고 해당 문장을 단일 구성 기준 참조로 바꿨다. 앞선 독립 리뷰의 ‘명백한 결함 미발견’ 기록은 삭제하지 않으며 완전한 무결함 판정으로 확대하지 않는다.

## 독립 적용

새 에이전트 `icon_layout_followup`에 수정 문서와 BB–BF 요청 5개만 전달하고 정답/앞선 평가를 제공하지 않았다. 파일 수정·제품 렌더 없이 spec-only 판단을 받았다.

| 사례 | 실제 응답의 판단 | 확인 |
|---|---|---|
| BB |20px 버튼+gap4px의 중심24px, 중앙44px 확장은20px 겹침. 실제 경계 클릭·가림 검증 요구 | 선언 크기만으로 PASS하지 않음 |
| BC | 브랜드 다색 유지, Lucide 기능 currentColor, 임의 fill 대신 지원 상태/표면 | 범위·반례 유지 |
| BD | 카메라 선행/다음 후행과 명시 요구, 로딩/누락/묶음 중심 확인 | 일률적 후행 규칙 재발 없음 |
| BE |1440 viewport에서1024 임계값도 발동하지 않음. 컨테이너/형제폭과 전환 전후 확인 | viewport와 가용폭 구별 |
| BF | 실제 이벤트 대상·이중 실행·중첩DOM 확인. 시각/Tab 순서와 터치hover/selected 구별 | 박스겹침을 일괄 금지하지 않음 |

리뷰는 ui-composition의 ‘색·선 굵기·시각 크기를 통일’이 단독으로 브랜드까지 확대될 수 있다고 지적했다. 이를 ‘같은 역할의 기능 아이콘 범위’로 한정하고 다색 브랜드의 일괄 변경을 제외했다. 연결된 상세 문서의 기존 범위와 일치시키는 명료화다.

## 검증과 한계

형식·링크/앵커·공백·규칙 불변 결과는 [후속 정적 검증](icon-layout-validation.json)에 기록한다. 근거가 있는 문서 모순 수정과 1회 독립 spec-only 적용이며 실제 컴포넌트의 클릭·렌더·터치·스크린리더 통과가 아니다.5개 사례를5회 독립 반복으로 세지 않는다. Python 판독기·catalog를 변경하지 않아 그 테스트는 이번에 실행하지 않았다.
