# reference-decompose 첫 실험

실제 작업일2026-09-10 Asia/Seoul. 사용자 요청: 원본 한 장 → UI 요소 분리 → 요소별 프롬프트 → 그 프롬프트로 구현 → 사용자 교정 → 프롬프트와 스킬 보완. 후속 요청은 이번 작업과 교정을 실제 오늘 날짜로 계속 커밋하는 것이다. 이전9월9일 날짜 요청을 이번 커밋에 재사용하지 않는다.

## 기준 상태

기존 상세 분석 지침으로 독립 에이전트가 작성한 [기준 프롬프트](reference-decompose-baseline-prompt.md)를 보존했다. Git 공백 검사에 맞춰 Markdown 줄끝 공백만 정리했고 문구는 바꾸지 않았다. 좌표계/관찰과 선택, 체크박스의 카드 밖 위치 등 중요한 관계는 기존 지침으로도 잘 설명했다. 따라서 기존 스킬로 모든 분석이 실패한다는 결론은 아니다.

반면 독립 요소를 그대로 재생하는 입력 묶음·최초 렌더와 교정 버전 보존은 별도 계약으로 제시하지 않았고, 실제로 확인되지 않은 날짜 이동/드래그/저장 동작을 chosen으로 추가했다. 새 스킬은 원본 번역·재현 실험·제품 적용의 범위와 산출물을 구별한다. 선택 동작을 원본에서 관찰된 것처럼 기록하지 않는 기존 장점도 보존한다.

실제 이전 대화의 레퍼런스 미반영 실패는 session-context의9월9일 기록에 있다. 새 실험과 그 실패를 동일한 통제 실험으로 부르지 않는다.

## 실제 입력과 구현

[P1](../../design/reference-language/round-01/prompt-v1.md)을 먼저 작성하고 원본 접근이 없는 구현 담당에게 전달했다. 전달한 사진은 원본에서 추출한 사진 영역뿐이고 UI 글자·컨트롤·레이아웃은 HTML/CSS로 구현했다. E1–E5 독립 표본과 조립 화면은 동일한 컴포넌트 마크업/CSS를 썼다. [관찰/입력 격리 기록](../../design/reference-language/round-01/analysis.md).

최초 렌더에서 구조와 비율은 대체로 보존됐으나 Day3의 카드 경계가 빠졌다. 원본에 보이는 경계를 P1이 사진 조각으로 축소해 설명한 실제 번역 누락이다. P1/최초 렌더를 보존하고 [P2](../../design/reference-language/round-01/prompt-v2.md)를 별도 입력으로 추가했다. 가려진 내용이 unknown이어도 보이는 컨테이너 경계까지 버리지 않는 조건과, 원본에 경계가 없으면 추가하지 않는 반례를 스킬에 보완했다. 사용자 지적을 받았다고 꾸미지 않으며 내부 발견 F1이다.

후속 토큰화와 의미 마크업/커서 교정은 구현 품질 보강이다. 후속 리뷰에서 구현 담당에게 원본 접근을 허용했으므로 P2/최종 결과를 새 blind sample로 부르지 않는다.

## 행동 시뮬레이션

동일한 기준 평가 담당에게 새 스킬과 실제 요청5종을 주었다. 이는 새로 격리된5회 모델 실행이나 통계적 검증이 아니라5개 상황의 독립 담당 검토다.

| 입력 | 실제 선택 | 판독 |
|---|---|---|
| 검색 결과만 | 출처와 확인 상태만 전달, 분해/구현하지 않음 | 범위 보존 |
| 295px 원본, CSS/DPR 미상 | image-px와 chosen CSS/비교 폭을 구별 | 가짜 실측 없음 |
| 사진이 작다는 사용자 지적, 렌더 없음 | 사용자 관찰로 보존, 원인은 가설, 즉시96px 보편 규칙화하지 않음 | 교정 근거 구별 |
| 공유 간격을 참조하는 E4 prompt-only | 공유 계약·슬롯 간격까지 포함한 입력, 구현은 생략 | 단독 문단의 문맥 누락 방지 |
| 픽셀 재현과 기존14px/선 금지 충돌 | 관찰을 보존하고 적용 차이를 명시, 픽셀 동일 주장 안 함 | 구체 제약 보존 |

평가자가 prompt-only에도 실험 구현이 강제되는 것으로 읽힐 여지를 지적했다. ‘실제 구현을 포함한 프롬프트 검증’으로 조건을 구체화했다. E-ID가 다른 입력의 번호와 혼동되지 않도록 출처/버전과 함께 식별하도록 보완했다.

## 검증과 한계

새 스킬과 연결 스킬3개 형식 검사 통과. 실제 브라우저/코드·시각 판독은 [실험 리뷰](../../design/reference-language/round-01/review.md)와 [게이트 리뷰](../../design/reference-language/round-01/gate-review.md)에 기록한다. HTML/CSS 정적 실험이며 TS/JS 제품 코드와 AI 기능은 추가하지 않았다.

사용자 품질 교정은 아직 받지 않았다. 한 화면의 초기 실험이며5회 이상의 fresh-context 반복 재현, 다른 업종 화면으로의 전이 정확도는 미검증이다. 이 상태를 범용 스킬의 정확도 보장이나 제품 출시 완료로 보고하지 않는다.

최종 문서 검증: 변경/신규 Markdown19개에서 로컬 파일 링크125개 확인, broken0. 이는 경로 존재 검사이며 모든 anchor 자동 검증 수치로 부르지 않는다. git diff --check와 새 스킬 형식을 재확인했다. 실행에 사용한 브라우저 검증 스크립트는 기존 Oxlint/anti-slop 설정으로 lint, 임시 경로의 Node 타입을 사용한 checkJs를 통과했다. 기존 제품 의존성은 바꾸지 않았다.
