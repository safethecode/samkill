# 스킬 없는 기준 실행

2026-09-06, 독립 subagent `skill_baseline`, 스킬을 전달하지 않고 가상의 A–E 과제를 실행했다. 도구 호출과 실제 이미지 확인은 없는 합성 평가다. 아래는 실제 응답에서 추출한 판단과 누락이다. 통과한 항목을 실패로 바꾸어 기록하지 않는다.

## A: 리서치 — 검색 규칙 실패

응답은 `search_ui_patterns` → `search_components` → OCR 두 번 검색의 순서를 제안했다. 또한 “결과가 부족하면 국가 필터를 먼저 풀고, 국내외 사례를 구분하겠습니다.”라고 했다. 하나의 복합 필터 요청으로 해결할 의도를 반복 검색하고 한국 조건을 임의 변경하는 문제다. 출처·미확인 동작을 기록하고 정지 화면에서 동작을 단정하지 않는 점은 통과했다.

## B: 구현 명세 — 핵심 판단 통과, 전달 계약 누락

“기존 브랜드 보라색과 그라데이션 기본 CTA를 유지합니다.”라고 했고 R1의 관찰과 새로운 설계 제안을 구분했다. 밀도·일괄 선택·긴 한국어·부분 실패도 반영했다. 그러나 적용 결정별 구현 대상/시각·행동 검증 기준이 연결되지 않았다. 신규 스킬은 이 누락을 구조화하되 브랜드 존중 등 이미 통과한 행동을 회귀 검사한다.

## C: 리뷰 — 검증 한계 통과, 수정 우선순위 계약 누락

“현재 근거로는 출시 승인 보류입니다.”라고 했고 빌드와 시각 검증을 구분했다. 구조 차이를 지적했으나 판단 근거 종류와 P0/P1/P2, 재검증 상태를 항목별로 남기지 않았다. 새 스킬의 목적은 단순 불합격 유도가 아니라 수정할 수 있는 근거 기록이다.

## D: 문구 — 사실 보호 통과, 구현 전달 계약 누락

“결제를 완료하지 못했습니다”를 제시했고 과금 여부·오류 원인·복구 행동을 지어내지 않았다. “레퍼런스의 ‘결제 실패 / 다시 결제’는 표현 참고이며, 재결제가 가능한 근거는 아닙니다.”라고 했다. 문자열 ID, 노출 조건, 인터랙션 연결, 길이/읽기 검증 슬롯은 없다. 새 스킬은 기존의 신중한 판단을 유지하며 구현 계약을 추가한다.

## E: 온보딩 — 출처/가정 구분 통과, 전이 계약 누락

R2 한 장만 관찰한 사실을 명시하고 나머지는 제안으로 표시했다. 선택 동의·네트워크 실패·중복 생성 문제는 다뤘다. 그러나 화면/상태 ID와 전이 표, 뒤로 가기·재진입 정책, 회복 후 검증 경로가 빠졌다. 신규 스킬은 모든 플로우를 관찰했다고 꾸미는 문제를 이미 해결했다고 가정하지 않고 이를 회귀 조건으로 유지한다.

## 한계

단일 기준 실행이다. 5회 이상 fresh-context 반복 비교나 실제 UI 구현 A/B 실험을 수행한 결과가 아니다. 지침 효과의 통계적 증거로 사용하지 않는다.
