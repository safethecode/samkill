# 라운드4 · 레퍼런스 조합과 스타일 관계

2026-09-10. 단일 원본 복제 평가에서 제품 아이디어의 조합·각색 평가로 바뀐 사례다. 원본 미공개 구현 실험으로 부르지 않는다.

## 실제 실패와 변경

사용자는 P1–P3의 색·배치·느낌·스타일이 원본에서 멀어졌다고 지적했다. 크림 바탕/초록 정보/동일 베이지 퀵메뉴/중립 시간 버튼을 선택한 결과와 부분 판정의 오류는 [거절 스냅샷](../../design/reference-language/round-04/evidence/user-rejected-p3/rejection-review.md)에 보존한다. 이후 에이전트의 원본 주황색 복구 해석도 사용자가 교정했다. 요구는 커스텀 색을 허용하되 원본의 선택 관점과 효과를 파악하는 것이다.

[스타일 분석](../../design/reference-language/round-04/style-analysis.md) → 구현 전 [P4](../../design/reference-language/round-04/prompt-v4.md) → 실제 앱으로 연결했다. 색 역할과 그림 표현, 사진 비중, 그룹 간격을 함께 바꾸었다. reference-decompose에 화면 스타일 계약을, reference-synthesis에 각색 전 연결과 전체/부분 판정 경계를 추가했다. 특정 팔레트를 공통 지침으로 만들지 않았다.

## 실행한 검증

P4의 검색/지역/카테고리/테마, 저장과 탭 복귀, 상세, 날짜/시간/동반 인원, 조건 동의, 요약/수정/완료/취소 체험과 날짜 초안 회귀는 [P4 증거](../../design/reference-language/round-04/evidence/p4/)에 있다. 200% 시간 숫자 분리를 적응 열과 nowrap으로 고쳤고 고대비에서 사라지던 mask를 공식 inline SVG로 바꿨다. 실제 렌더와 자동 결과를 함께 판독한다.

보드1100/390/320px에서 사진, 실제 iframe 폭, 필터/초기화, 프롬프트 펼침/닫힘, 키보드/고대비 초점을 실행했다. [보드 결과](../../design/reference-language/round-04/evidence/p4-board-checks.json), [비교 화면](../../design/reference-language/round-04/index.html), 최종 개별 판정은 [리뷰](../../design/reference-language/round-04/review.md)를 참조한다. lint/typecheck는 앱과 변경한 검증 코드에 수행했다.

## 평가 한계

스킬 문구의 변경 전/후 각5회 fresh-context 평가를 계획했으나 도구의 전체 스레드 한도로 첫 독립 표본 생성이 거절됐다. 담당자의 슬롯 조회가 기존 리뷰 답변도 반환해 직접 후속 분석은 비유도 대조군이 아니다. 미실행 표본을 다른 이름으로 통과시키거나 CLI로 제한을 우회하지 않았다. [담당 진단](reference-style-contract/)은 해당 노출과 수행 범위를 명시한다. 실제 사용자 거절은 변경 전 실패 근거이나 반복 실험의 대체 통계는 아니다.

원본의 고유 일러스트를 공식 Lucide로 각색한 표현 차이가 남는다. 원본 제작자의 실제 의도, 새 규칙의 범용 정확도, 실물폰/Safari, 실제 매장/API/예약, P4의 사용자 품질 승인은 미검증이다. 로컬 프로토타입 검사와 이 한계를 구별한다.

후속 검증: 전체 앱/검증 JS14개의 lint와 checkJs를 대조하면서 초기 검증 스크립트 두 사본의 빈 배열·헬퍼 인자·카테고리 tuple 추론 누락을 발견했다. JSDoc과 명시된 tuple 배열로 보완해 통과했으며 규칙 비활성화나 반복 단언을 사용하지 않았다. 최종 판독 중 발견한 예약 내역 상태 배지의 역할과 200% 퀵메뉴 끝음절 고립도 국소 교정했다. 기본 화면4열은 유지하고 확대에서2열로 적응한다. 역사 스냅샷62파일 해시 불일치0을 확인했다.

최종 로컬 게이트: 활성75+프로젝트7=82항목 중 pass59/명시예외17/not-applicable6, FAIL/UNVERIFIED0. 실제 판독을 기록한 뒤 CLI 무결성 검사를 부모도 재실행해 PASS를 확인했다. 문서/보드의 현재 링크126개 누락0, 커밋 대상 공백 오류0이다. 이 결과는 앞서 명시한 스킬 독립 반복 평가 미실행이나 사용자 품질 승인 대기를 해제하지 않는다.
