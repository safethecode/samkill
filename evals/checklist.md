각 행의 지침 점검: 이름/description 트리거, 필요한 입력, 관찰·추정 구분, 출력 슬롯, 종료 조건, 예시, 실제 필요한 참고 문서 링크, 원본 지침과 충돌 없음. 적용 평가는 관찰 가능한 결정을 채점하며 표현의 일치 여부를 성공으로 세지 않는다. 실패와 후속 수정은 results에 기록한다. 외부 서비스 호출·실제 UI 렌더링 검증과 합성 사례 검증을 구분한다. 사용자의 후속 요청에 따라 스킬별로 커밋하고, 공통 문서·템플릿·평가 기록도 별도 커밋으로 묶는다. 원격 푸시는 이번 요청에 포함하지 않는다.

한국어 문구 추가 요구: 사용자 제공 토스 원칙 반영 완료. 기존 스킬 기준 실행은 korean-copy-baseline.md, 새 변형 사례 결과는 korean-copy-green.md에 기록했다. 추가 6개 사례와 8원칙 적용 근거를 직접 검토했고, 사실·조건·가능성 보존을 확인했다. 해당 후속 평가는 초기 다섯 스킬 평가와 별도로 취급한다.
