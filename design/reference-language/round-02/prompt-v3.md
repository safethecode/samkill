# R2/P3 — 독립 표본의 가용 폭 보존

P1+P2+이수정문이 최신입력이다. 내부리뷰에서발견한 구현문맥 차이를수정한다. 원본을구현담당에게보여주지않고 측정한박스와수정조건만전달한다.

P2의독립표본페이지는바깥설명컨테이너의좌우padding24px때문에390뷰포트에서표본폭342px,검색폭310px이됐다. 조립화면의표본폭390px/검색폭358px과달라,같은필터도독립표본에서만2줄로변했다. 같은CSS를썼다는사실로같은레이아웃을보장하지못했다.

수정: 독립표본의유효폭은조립화면과같게유지한다.390뷰포트에서표본390px/검색358px,320뷰포트에서표본320px/검색288px. 페이지설명/요소제목의여백은그텍스트가소유하고 실제표본을감싸는상위요소의가용폭을줄이지않는다. 화면좌우16px은표본안공유컨테이너에서딱한번적용한다.

확인: 같은폭에서조립과독립의검색박스너비·x위치,필터줄수,식별영역폭·아바타크기,설명폭을대조한다. 설명표본에만필요한세로여백은표본밖에두고조립의박스수치를바꾸지않는다. 다른폭에서보이도록요청받은표본은그차이를명시적으로라벨링하는것이반례다.
