# R2/P2 — 식별 영역 높이의 모순 수정

P1+이수정문을 실행입력으로 사용한다. 원본을 본 분석담당의 내부교정이며 사용자 지적은 아직 없다. P1·최초3개소스·최초390/320렌더를 evidence에 보존했다.

P1은 E4식별묶음을48px이라고 하면서 이름24px+아래간격8px+배지(줄20px+상하padding4px)=56px을 지정했다. 두조건이 양립하지 않아 구현이 세부값을 따라 카드188px/둘째시작380px으로 늘었다. 오류는 구현자가 아니라 번역 계약의 수치 모순이다.

수정: 이름줄24px,이름과메타사이gap2px,메타배지줄20px+상하padding각1px=22px로 정한다. 합계24+2+22=48px로 아바타와 동일한 상단묶음이 된다. badge좌우padding6px/메타아이콘14px/글자14px/색/정렬/카드상하16px은유지한다. 원본의 이름과메타가가깝게묶인관계에따른 chosen값이다.

390px에서첫카드min-height180px,둘째카드시작y372px을다시확인한다.320px에서긴이름/메타/설명이더많은줄을필요로하면48px고정을강제하지않고늘어나게둔다. 사용자글자하한을깨거나숨겨맞추지않는다. 같은토큰을쓰는독립표본과조립에함께적용한다.
