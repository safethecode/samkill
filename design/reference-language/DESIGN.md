# 레퍼런스 언어 번역 실험

## Overview

사용자와 함께 원본 → 요소별 언어 → 프롬프트 구현 → 교정의 정확도를 높이는 작업이다. 첫 대상은 기존에 확보한 셀레트립 일정 편집 화면 한 장이다. 제품 재설계·저장·드래그 기능 구현은 이번 범위가 아니다. [1차 입력](round-01/prompt-v1.md)은 구현 전에 고정했다.

## Colors

사진은 원본에서 분리한 에셋. 흰 표면/검정 주 글자/회색 보조와 비활성 버튼을 선택했다. 원본 CSS 색은 미상이다. 표본의 확정값 관리 원본은 round-01/ui.css, 실험 보드의 색은 표본과 별개인 round-01/board.css다.

## Typography

원본 서체·CSS 글자 크기는 미상. 시스템 sans-serif와14px 하한을 적용한다. 제목18px, 그룹16px, 장소정보14px를 선택했으며 원본과의 차이를 비교에 남긴다. 실험 보드 설명은 한국어 해요체, 원본 문구는 재현 표본에만 보존한다.

## Layout

295×640 image-px 원본 중 OS 영역을 제외한 y44–628을390px 폭에 표시한다. 표시 배율만 맞췄으며 원래 CSS viewport를 알아냈다는 뜻은 아니다. 체크박스가 카드 밖, 사진이 카드 높이를 채움, 그룹 간격>행 간격을 핵심 관계로 본다. 화면 코드의 프레임은 정적 비교용이며 원본 앱의 스크롤·고정 동작은 미확인이다.

## Elevation & Depth

장소별 외곽 경계와 날짜 선택 컨트롤 경계는 보존한다. 원본 하단 장식 수평선은 RUI-14에 따라 생략한다. 큰 그림자·별도 장식 표면은 추가하지 않는다.

## Shapes

날짜 pill과 장소 사각형, 하단 버튼의 반경은 역할을 구별한다. 뒤로가기와 순서 표시는 공식 Lucide SVG를 사용하되 원본 패밀리와 같다는 주장을 하지 않는다.

## Components

E1 제목 행, E2 날짜 선택 표본, E3 날짜 그룹 제목, E4 짧은/긴 장소 행, E5 비활성 완료 버튼. 독립 표본과 조립은 같은 ui.css를 쓴다. 브라우저 기본 checkbox는 선택과 포커스를 시험할 수 있으나 저장/날짜이동/드래그는 정적 관찰 대상이다.

## Do's and Don'ts

구현 담당은 prompt-v1.md와 분리된 사진/아이콘만 읽는다. 원본을 본 담당이 별도로 실제 화면을 비교한다. 첫 입력·렌더와 이후 수정 입력·렌더를 보존한다. 사용자 교정 대기 상태를 승인으로 바꾸지 않는다. 범용 스킬 검증이나 제품 전체 게이트 통과를 한 사례로 주장하지 않는다.
