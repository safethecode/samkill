# 조사 누적

|분기|검색|결과와 채택|
|---|---|---|
|B1 요리 탐색|레시피|냉장고털기 AI 빈화면·검색,CREME 검색. 검색 화면만으로 주 화면 품질을 정하지 않음|
|B2 재료 관리|식재료→재료|첫 검색0건. 동의어 재검색에서 냉장고털기 검색/카테고리/위치별 재료 확보. R3 카테고리 재료 직접 관찰|
|B3 사진 등록|카메라+운동&건강→촬영하기+운동&건강|첫 검색0건. 재검색에서 메디코치·앳플리·김캐디. R4 프리뷰/상단 닫기 채택. 권한은 실제 브라우저 처리|
|B4 상세/조리|상세정보+CREME|상세/레시피/팔로우 확보. R1 상세,R2 조리 채택. 팔로우는 범위 외|
|보완|메인+만개의레시피,Kitchen|0건. 선택된 R1/R2와 B2로 필요한 상세 및 관계 확보. 없는 앱 자료를 근거로 사용하지 않음|
|B2 보완|메인+냉장고털기|식단 캘린더/위치/홈 관찰. 카테고리 목록 중심 관계는 R3 사용. 파란 장식 냉장고/광고를 제품에 복사하지 않음|

- R4 [메디코치 촬영](https://uibowl.io/name/%EB%A9%94%EB%94%94%EC%BD%94%EC%B9%98?patterns=%EC%B4%AC%EC%98%81%ED%95%98%EA%B8%B0). references/R4-camera.png.

전체 반환 영상/연속 화면을 모두 봤다고 주장하지 않는다. 대표 화면만 직접 판독했고 추가 썸네일은 관찰 근거가 아니다. B1 목록 자체는 R1 사진·제목·메타를 재조립한 신규 구성이다. 원본 목록과 정확히 닮았다는 주장은 하지 않는다.
