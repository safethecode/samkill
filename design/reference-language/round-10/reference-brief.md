## O/E 상세 관찰(사진은image-px390/DOM viewport390CSSpx, 별도기록외시각추정)
- E1 첫사진: 좌우0, 높이약640imagepx. 두인물상반신이중앙, 위쪽14px가량흰이름/일정, 아래큰필기체제목과장소. 실제font-family/hover미확인. 검은gradient는사진위글자대비역할.
- E2 인사: 흰면의중앙제목20~24px/본문14~16px, 본문폭약250imagepx, 넓은상하여백으로문단구별.
- E3 달력: 연한중립면/7열/둥근진한선택날짜, 일시와장소가위. 날짜칸약44px추정.
- E4 갤러리: 3열작은정사각사진/간격작음. 한사진의소속은명확하나누락이미지있음. 확대동작미확인.
- E5 이동: 위치·주차·피로연을같은영역에서전환, 지도아래3개외부지도버튼과교통행. 일부지도이미지로드실패. 탭밑줄없음, 선택파란면.
- E6 RSVP: 진한갈색블록위흰글자/흰가로버튼, 상하여백약40px. 초기진입강제팝업. 폼의하객측2개선택/이름/연락처끝4자리/참석여부/제출은DOM직접확인. 제출하지않음.
- E7 계좌: 흰테두리접힘행/신랑신부분리, 왼쪽라벨오른쪽chevron, 바깥약20px·행간12px추정.
- E8 공유: 페이지끝흰영역/링크복사. 판매footer와워터마크는제작샘플용으로제외.

## 구현 전 구조 ASCII
R1 원본: 판매헤더 → 사진(이름/일정/영문제목겹침) → 인사 → 달력 → 인물소개 →3열갤러리 →스냅 →교통탭 →참석블록 →접힌계좌 →공유/판매푸터. 최초참석팝업이본문가림.
D1 제품: 이름 → 큰사진 →예식일시/장소 →인사·가족/연락 →달력/일정저장 →2장갤러리/확대 →장소/약도/지도/교통접힘 →참석응답 →신랑신부계좌접힘 →축하글 →감사사진/공유/빠른이동. 첫커버비교후의존영역구현.
주요행동대상: 일정저장은이예식/참석응답은이하객/계좌복사는해당예금주/공유는초대장. 전체페이지세로스크롤. 고정빠른이동은도구역할·마지막접근검증필요.
