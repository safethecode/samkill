# P4 · 색의 역할과 화면의 리듬을 복구하는 각색

2026-09-10. 사용자 거절 이후, 구현 변경 전에 고정한 입력이다. P1–P3와 거절 화면은 `evidence/user-rejected-p3/`에 보존한다. 원본 비공개 재현 평가가 아니다. 원본 제작자의 의도가 아니라 이미지에서 관찰되는 효과와 이번 설계 가설을 구별한다.

## 공유 스타일 계약

| 근거와 관찰 | 유지할 관계 | 이번 제품의 선택과 확인할 결과 |
|---|---|---|
| R1 검색은 회색 중립면. 큰 유색 배너와 서로 다른 그림의 퀵메뉴가 탐색 영역을 만든다 | 조작의 중립성, 그림의 풍부함, 영역별 다른 시각적 비중 | 검색은 연회색, 4개 카테고리는 같은 베이지 원을 제거하고 대상별 색/채움/실루엣을 가진 공식 Lucide로 표현. 광고 배너는 제품에 필요하지 않아 복제하지 않는다. 대신 테마 사진의 면적을 늘려 탐색의 시각적 중심을 만든다. 원본의 일러스트 풍부함을 완전히 재현했다고 주장하지 않는다 |
| R3 흰 면 위 동일 크기 사진과 바로 붙은 진한 제목 | 사진이 분위기를 전달하고 제목이 선택 판단을 이어감 | 두 열 사진을 현재 112px보다 큰 144px로, 사진 아래 8px에 14px/600 제목. 사진의 녹갈색을 앱 전체 팔레트로 확장하지 않는다 |
| R2·R4 흰 바탕/검정 정보와 채도 높은 시간 버튼 | 정보와 실행을 분명히 구별 | 바탕 #ffffff, 글자 #202124, 부가정보 #676b73. 실행 #245eea, 흰 글자. 따뜻한 사진과 청색 행동의 색온도 차이가 예약 위치를 드러내는지 실제 비교한다. 원본 주황색 자체는 유지 대상이 아니다 |
| R2 사진/이름/조건/시간은 가까우며 다음 매장까지 크게 쉰다 | 내부 결속과 그룹 사이의 쉼 | 매장 내부12px, 매장 사이32px. 시간은 해당 매장 아래에 묶고 full-width 3열 유지(14px/44px 조작을 보존하는 각색). 구분선 대신 간격으로 읽혀야 한다 |
| R5 선택 날짜/인원과 예약 시간은 같은 강한 색을 공유 | 선택과 최종 행동의 연결, 부차 조작과 대비 | 선택한 날짜/시간은 청색+흰 글자, 미선택은 중립 회색. 최종 CTA도 청색. 검색/저장/필터를 모두 강한 청색으로 칠하지 않는다 |

이 값은 새 선택이며 원본에서 추출한 HEX/정확한 CSS 값이 아니다. 청색은 이번 사진·행동 관계의 가설이지 다른 제품의 기본값이 아니다.

## E1–E6 수정 입력

- 공통: 최대430px, 가로20px 패딩 소유권 유지. 본문 및 조건14px 하한, 제목22px/섹션·매장이름18px. 페이지 #fff, 중립 조작 #f3f4f6, hover #e9edf3, 선택 보조면 #eaf0ff, 주 행동 hover #174bc5, 오류 #b42318. 역할 토큰에서 정의/참조한다. 경계선·탭 밑줄·슬로건을 추가하지 않는다.
- E1: 현 지역/검색 기능 유지. 검색의 연회색과 검정 텍스트로 중립 조작임을 드러낸다.
- E2: 4개 퀵메뉴/라벨/필터 기능 유지. 동일 원 배경을 제거한다. 공식 Lucide SVG의 실제 형상을 사용하되 paw는 살구색 면, coffee는 갈색과 크림색 면, shield-check는 파랑 면, trees는 녹색 면처럼 대상 구별에 필요한 그림 색을 사용한다. 그림 전체를 단색 mask로 평탄화하지 않는다. 새 SVG 경로를 발명하지 않고 기존 공식 경로의 fill/stroke와 개별 크기를 조정한다. 이 출처의 그림 역할을 복원하기 위한 범위 한정 선택이다. 선택은 슬롯 주위의 낮은 대비 면과 진한 라벨로 명확히 하며 그림을 바꾸거나 이동하지 않는다. forced-colors에서도 공식 SVG 선이 보여야 한다.
- E3: 두 열 테마 사진 144px, 사진/라벨8px. 제목 아래12px. 둘째 사진의 얼굴 crop은 기존 검증값 유지. 섹션 간36px로 검색/퀵, 테마, 목록의 영역을 구별한다. 넓어진 테마가 목록을 과도하게 밀어내면 첫 화면 비교에서 재조정하고 이유를 남긴다.
- E4: 이름/조건을 먹색/중립 회색으로 구별한다. 시간 선택은 청색+흰 글자로 실제 예약 진입임을 표시. 3열44px 이상, 시각적으로 해당 매장의 끝에 묶는다. 매장간32px. 200% 글자 확대에서 시간 숫자가 중간에 끊기지 않도록 `.slots button`의 숫자는 nowrap으로 보존하고 필요하면 가로 padding을 줄인다. 확대와320px 동시 조건에서도 겹침이 있으면 열을 줄이는 적응안을 적용한다.
- E5: 기존 날짜/시간/동반 인원/조건 동의/이전/닫기/초안/완료/취소 동작 보존. 미선택은 중립, 선택은 주 실행색, 최종 행동은 같은 색. forced-colors 선택과 초점이 식별되어야 한다.
- E6: 하단 탭64px/safe-area, 기존 기능 유지. 현재 위치는 작은 낮은 대비 선택면과 색/굵기로 전달. 큰 예약 버튼과 경쟁하지 않는다.

## 검증

390×844와320px 전체 화면을 원본과 같은 표시 폭으로 비교한다. 먼저 시선의 순서와 검색/탐색/예약의 구별, 다음 그림 표현·사진/제목 관계·매장 묶음을 판독한다. 기능이 있고 색이 바뀌었다는 이유만으로 스타일을 통과시키지 않는다. 밝은 기본 화면 외 상세/선택/확인/저장/예약도 같은 문법인지 확인한다. 기존 행동 회귀·200% 글자·forced-colors·키보드·reduced-motion 검사를 수행한다. 내부 판독 통과와 사용자 품질 승인은 구별한다.
