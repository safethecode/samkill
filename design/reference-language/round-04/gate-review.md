# P4 디자인 게이트 판독

2026-09-10. 내부 리뷰 범위는 로컬 Chrome의 모바일 카페 탐색/예약 체험과 비교 보드다. R1–R5 원본을 직접 열고 390/320 실제 화면·동일 표시 폭 Q 비교를 읽었다. 원본 CSS viewport/DPR와 제작자의 실제 의도는 미상이다. P4는 색 역할·사진과 그림·간격 관계를 각색한 제품이며 원본복제나 사용자 품질 승인이 아니다.

## 이전 실패와 판정 철회

사용자가 거절한 P1–P3는 `evidence/user-rejected-p3/`에 앱3개·DESIGN·P1–P3·reference-brief·sources와 독립 실행 증거/해시로 보존했다. 부모가 보존한 이전 보드 byte는 그 안의 board/에 별도로 있다. 아카이브는 당시 상대 링크를 보존했으며 독립 실행 배포물은 아니다.

당시 Q1–Q4 adapted 판정은 기능과 부분 배치 관계만 보고 전체 색·느낌·영역 구분까지 확인한 것처럼 확대한 오판이었다. review.md의 후속 기록으로 철회했다. 사용자 지적에 따른 RUI-16/17·PROJECT-REFERENCE-SYNTHESIS FAIL은 지우지 않는다. 당시 최종 게이트 PASS는 출력하지 않았다. failure-events에는 이 사실을 manual-user-review 이벤트로 구별해 보존하며 실제 CLI 실행으로 꾸미지 않는다.

## 코드·토큰·실행의 범위

앱과 독립 검증4개JS의 기존 anti-slop Oxlint/checkJs를 실제 실행했다. 부모가 별도로확장한검증JS 전체결과는 부모기록과구별한다. 역할토큰의 미정의/미사용은0이며 직접값예외는0/100%/grid반복수/미디어조건/예시사진crop좌표/공식SVG원경로에한정한다. CSS색·간격·크기·굵기·폰트·모션은역할토큰으로연결한다. 상세/메인/시트의20pxinset과하단가림방지를실제박스로검산했다.

청색면/흰글자 대비5.43:1,hover7.37:1,회색글자/흰면5.35:1,회색글자/중립면4.86:1이다. 수치는실제선택HEX에대한계산이며원본색측정이아니다. SVG경로는로컬공식자산과geometry를대조했고범위한정색/채움각색을구별했다.

catalog v4 활성75개 각각의 적용/원래checks/이유/예외/증거는 gate-contract.json과gate-report.json에있다. 카테고리그림에2색상한을강제하거나원본관계와무관한숫자통일을품질판정으로쓰지않는다. 예외는그림내용,터치상시조작,관례icon-only,참조의동일격자,모바일헤더/아이콘/3pxnavgap,동기식체험의가짜loading생략 등해당역할에만한정한다. 예약상태색과흰글자굵기같은별도문제는예외로숨기지않고수정했다.

실제매장정책/재고/법적허용/예약전송/API/결제/로그인/실물폰키보드/iOS Safari는이번로컬프로토타입의검증범위밖이다. 로컬입력과행동의검증을이범위의승인으로확대하지않는다. 스크립트PASS는판독기록의무결성이며자동미관평가나사용자승인이아니다.

최종 판독 범위의 총괄은 aligned다. 실제 CLI 무결성 결과는 PASS이며 활성75개+프로젝트7개=82개 중 pass59/exception17/not-applicable6이다. 미실행 필수 항목을 삭제하거나 unknown을 pass로 바꾸지 않았다. 사용자 품질 승인과 실제 운영 검증은 위의 범위 밖으로 구별한다.
