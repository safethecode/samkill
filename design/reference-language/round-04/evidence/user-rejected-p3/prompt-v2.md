# P2 · 첫 메인 비교 후 조합 정리

원본R1/R2/R3과390/320첫메인을직접비교했다. Q1검색/지역범위,Q2균등퀵메뉴,Q3사진두열/직하라벨,Q4사진/조건/매장시간소속은각색후유지됐다. 첫카페가능시간하단680px<하단탐색시작780px로첫예약진입점이보인다. P1코드/렌더를보존하고아래교정후상세/예약E5를확장한다.

## 원본 장점과 현재 그림의 차이

둘째테마 dog.jpg의현재object-position center55%는강아지눈/머리위를잘라테마이미지식별성을떨어뜨린다. center35% 부근을선택해실제렌더에서얼굴전체를포함하고사진두열112px높이/라벨관계는유지한다. 원본이미지좌표가아닌우리소재의crop판단이다.

## 제품 공통 언어의 정합성

최초의12px반경/5단계글자/14pxgap/여러색퀵면은관찰핵심을보존하는데필수인값이아니다. 이번각색에서는과거원본재현예외를그대로확장하지않고공통기준과맞춘다. 사진/검색반경8px,카페사진-정보gap12px,타이포22/18/14px세단계로통일한다. 주제목22,섹션/매장이름/일반본문·입력18,메타/버튼라벨14. 같은role은기존lineheight와크기가맞는지검산한다. 원래body16px를pagepadding토큰으로겸용하지말고layout의16px는별도역할로보존한다.

퀵메뉴기본슬롯면은모두중립 #f3eee4,그림은진한본문색,선택한메뉴만초록선택면/굵기로구별한다. 각카테고리의다른의미는모양과라벨로표현한다. 저장/nav/주CTA의아이콘은공식Lucide에CSS mask+currentColor 또는공식경로inlineSVG를적용해글자와같은역할색으로연결한다. 직접그린새경로는없다.

매장목록은ul/li로의미구조를만들고기본margin/padding/list-style을reset해현재배치유지. 한국어조건은word-break:keep-all을기본으로해서320에서'확인'의끝'인'만분리하지않는다. 긴조건에는자연높이를허용하며크기/실내·마당범위/이동가방조건삭제금지.

상시시간3개와저장icon-only는모바일탭탐색및카드에속한선택의발견성을위해유지한다. hover-only로숨기지않는다. 해당규칙의예외범위는이두역할과44px터치/접근가능한이름에한정하고최종행동을검증한다. 장식반경/색·간격예외로확대하지않는다.

위변경은내부리뷰교정이며사용자가직접수치지정한것이아니다. P1을소급고치지말고공유DESIGN기준/후속렌더를동기화한다. 수정후핵심Q의퇴보가없으면E5상세/예약과정전부구현한다.

제품문구 후속: 지역선택이별도인현재검색범위에맞춰placeholder/접근가능한이름을 `카페 이름 검색`으로명확히한다. 성수조건안에서지역명연남을검색하는것을전역지역검색처럼약속하지않는다. 지역은상단선택에서바꾼다.
