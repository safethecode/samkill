# P5 · 카페 사이의 표면 구분

2026-09-10. 사용자: 전체 수정은 긍정적이지만 각 카페 목록이 구별되지 않는다. 흰색/회색 교대 배경처럼 매장 단위가 보여야 한다. 구현 전 고정한 후속 입력이다.

E4/Q4 수정: 사진·이름·동반조건·예약시간을 하나의 article 표면으로 묶는다. 보이는 목록 순서에 따라 흰색과 기존 중립 surface #f3f4f6을 번갈아 사용한다. 회색을 상태나 선택 의미로 사용하지 않는다. 필터 결과와 저장 목록에서도 보이는 순서에 따라 같은 기준을 적용한다.

각 article 배경을 화면 공통20px inset 밖까지 확장하되 내부에 같은20px을 한 번 부여하여 사진/제목/시간의 기존 가용폭과 좌우 정렬을 보존한다. article 상하16px(기존 항목간32px의 절반), 목록 gap0으로 내부 여유와 인접 항목간 쉼을 연결한다. 첫 항목만 상단padding0으로 기존 첫사진/예약시간의 세로 위치를 유지한다. 별도의 선·그림자·반경·선택 표현을 추가하지 않는다. 빈 결과에는 article이 없으므로 배경/내부여유를 적용하지 않는다.

기존 검색·퀵메뉴·테마·상세·예약·하단탭의 표현은 유지한다. 원본 R2의 같은 매장 정보와 시간의 소속을 이번 사용자 요구로 더 분명히 하는 각색이며 원본에 교대 배경이 있다고 주장하지 않는다.

검증: 실제390/320 화면에서 적어도3개 매장을 스크롤해 흰/회/흰 영역과 각 시간의 소속을 확인한다. 기본 가용폭/첫시간 위치, 필터 후 순서, 저장 목록, 빈 결과, 200% 확대/고대비 환경에서 항목 관계를 확인한다. 고대비에서 배경색이 제거되어도 기존 간격/제목/사진으로 그룹을 유지하며 금지 구분선을 새로 만들지 않는다. 예약 진입과 복귀를 실행한다.

교훈의 범위: 교대 배경을 모든 목록의 기본값으로 만들지 않는다. 간격만으로 관계를 충분히 전달하지 못한 이번 목록에 표면 단계를 적용한 교정이다. 이전 사용자 지적과 판정은 보존한다.

## 추가 입력 · 조건 태그와 셀렉트

목록 배경 작업 중 사용자가 데일리호텔의 [당일사용가능] 같은 태그와 아이콘, 셀렉트 커스텀을 추가 요청했다. 이 추가 변경 전에 입력을 고정한다.

- R3의 짧은 정보 배지를 입장조건에 적용한다. 사진 오른쪽 가격 아래 `실내 동반`(house) / `마당 동반`(trees), `10kg 이하` / `크기 제한 없음`(paw-print)을 정적 정보 태그로 표시한다. 크기 태그와 추가 문구의 의미가 중복되지 않게 이동가방 필수/실내 동반 불가를 따로 남긴다. 맹견 전용 대관은 paw-print 태그와 단독 이용·입장조건 사전 확인 문구로 표시하며 일반 마당 조건에서 크기 제한 없음을 추론하지 않는다. 공식 로컬 SVG 경로를 재사용한다.
- 배지는 14px, 아이콘16px, 작은 사각 모서리4px, 낮은 대비의 청색 글자/옅은 청색면으로 정보임을 드러낸다. 주 예약은 기존 강한 청색, 필터는 실제 button으로 구별한다. 태그는 span이며 클릭/포커스 대상으로 만들지 않는다. 긴 태그는 가용폭 안에서 단어 단위 줄바꿈한다.
- 지역/인원/반려동물수 select의 닫힌 필드를 공통 래퍼로 통일한다. 네이티브 화살표를 제거하고 공식 chevron-down SVG, 중립면·8px반경·44/48px높이·12px좌우기본여백·화살표공간을 적용한다. focus-visible과 hover를 공통 토큰으로 연결한다. 옵션 선택은 네이티브 select의 키보드/OS 팝업 동작을 유지한다. OS 옵션 팝업 자체를 커스텀 구현했다고 주장하지 않는다.

기본/확대에서 태그 텍스트·아이콘·조건 손실과 셀렉트 현재값/화살표 겹침을 확인한다. 선택과 실제 목록/요약값 반영, 키보드 변경, 고대비 포커스/화살표를 확인한다.
