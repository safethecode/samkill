# P6 · 저장 하트의 활성 표시와 테마 호버 제거

2026-09-10 사용자 교정: 좋아요를 눌러도 활성화되지 않는다. 테마로 둘러보기에는 불필요한 호버가 들어갔다.

구현 전 재현에서 저장값 green/aria-pressed=true는 반영됐지만 SVG fill은none,색은기본먹색이었다. 저장 기능과 별개로 실제 활성 표현을 놓친 실패다.

E4 저장 버튼만 save-toggle 범위로 지정한다. 기본은빈하트,저장은기존accent의채운하트와낮은대비선택면,해제는빈하트로돌아간다. hover중에도활성모양/색을유지한다. 크기·사진/정보정렬은바꾸지않는다. aria-pressed와localStorage/저장목록도동기화한다. 고대비에서도채움/윤곽의차이를확인한다.

E3 테마는공통button:hover배경을받지않고hover진입/해제표현을제거한다. 키보드focus-visible과클릭후테마필터는유지한다. 다른버튼의hover나모든키보드초점을함께제거하지않는다.

390/320에서누름/hover/해제/키보드/재로드/저장탭동기화,테마hover전후동일표현과focus/필터동작을실행한다. 저장데이터나ARIA검사만으로아이콘활성화완료라하지않는다.
