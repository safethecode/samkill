# P5 디자인 게이트 판독

2026-09-10. 로컬 Chrome의 390/320 카페 탐색·예약 체험과 비교 보드를 검토한다. 이전 P4 판독은 [당시 사본](evidence/p4-before-row-surfaces/gate-review.md)에 보존했다. 현재 P5의 최종 증거는 `evidence/review-p5/`에 둔다. 원본 CSS viewport/DPR와 제작자의 실제 의도는 미상이며 관찰된 효과와 이번 구현 가설을 구별한다. 아래 판독은 원본 복제나 사용자 최종 품질 승인이 아니다.

## 사용자 교정과 이력

P1–P3의 전체 색·느낌·구획을 충분히 읽지 못하고 Q1–Q4 부분 adapted를 확대한 오판은 [review](review.md)에서 철회했다. `evidence/user-rejected-p3/`의 거절 앱·기준·증거를 보존한다. P4에서는 전체 개선에 대한 긍정적 피드백과 함께 카페별 구분 부족이라는 후속 지적을 받았다. 간격만으로 충분하다는 P4 RUI-25 판독은 해당 범위에서 철회한다. 커밋 `5b026fa`와 주요10파일이 일치하는 [감사 기록](evidence/p4-before-row-surfaces/baseline-audit.json)을 남겼다. 각 사용자 FAIL과 실제 CLI 이벤트는 [누적 기록](failure-events.jsonl)에서 구별한다.

P5는 교대 표면을 먼저 고정하고 조건 태그/아이콘, 닫힌 select 외형, 마감 날짜 보조행 제거를 순차 추가했다. 최초 입력에 모두 있었던 것처럼 기록하지 않는다. 태그 구현 후 사진 고정높이보다 조건이 길어진 문제는 별도 사용자 교정으로 보존하며 최종 사진 맞춤 검증을 이어간다. 중간 증거는 `evidence/p5-surfaces-before-tags/`, `evidence/p5-before-photo-fit/`에 보존한다.

## 원본과 실제 조합

|Q|새 판독|범위와 차이|
|---|---|---|
|Q1 검색|R1의 중립 검색과 전체 목록 범위를 지역 select/검색으로 전달한다. 닫힌 지역필드가 중립면·공식 화살표를 공유하고 청색 예약시간과 구별된다.|브랜드·알림·광고를 가져오지 않는다. OS 선택 팝업 자체는 커스텀이 아니다.|
|Q2 퀵메뉴|원본의 채움/외곽선/대상별 실루엣 관계를 공식 SVG의 개별 색과 형상으로 각색했다. 기본4열/확대2열과 읽는 라벨을 유지한다.|원본 고유 일러스트의 질감·세부·풍부함과 완전 동급은 아니다. 숫자 색상 상한으로 다시 일괄 중립화하지 않는다.|
|Q3 테마|R3의 사진 중심2열과 직하의 진한 이름을 유지한다. 큰 사진영역은 회색검색/작은그림/강한시간과 다른 탐색 역할이다.|할인·별점은 허위로 추가하지 않았다. R3 정보배지는 P5 Q4의 조건태그에도 연결한다.|
|Q4 카페·시간|R2의 사진/정보/시간 소속에 P5 흰·연회색 article 표면을 추가했다. R3의 짧은 정보배지 역할은 실내/마당/크기조건 태그로 각색했다. 정적 옅은 태그와 강한 청색 예약시간이 구별된다.|원본에 교대 배경이나 같은 태그 아이콘이 있다고 주장하지 않는다. 각색 이유는 이번 사용자 요구와 소속 관계다. 태그는 span, 비클릭·비포커스다. 맹견대관에 크기제한없음을 추론하지 않는다.|
|Q5 예약조건|R5의 선택된 날짜·시간·인원 관계를 공통 입력으로 옮겼다. 마감날짜는 disabled/접근이름을 유지하면서 시각 보조행을 제거해 기본7개 날짜44px가 같다. 인원/동물은 공통 닫힌 select와 화살표를 쓴다.|한 주의 가상 일정이며 원본 월력 복제가 아니다. 긴 날짜표시는200% 자연높이로 늘고 단일 상태보조행이 형제를 늘리지 않는다.|

전체에서 흰 중립면/먹색 이름/사진과 표현 있는 그림/옅은 조건태그/청색 실행의 강도를 비교했다. 색을 원본 HEX로 바꾸거나 기능이 동작한다는 이유만으로 결합 품질을 통과시키지 않는다. 카페 배경은 선택상태가 아니며 필터·저장 후 보이는 순서로 흰/회색을 배정한다. 고대비에서 배경색이 제거되어도 제목·사진·내용 사이 쉼으로 매장 소속을 읽는다.

## 실제 실행과 근거

- `verify-review-p5.cjs`: 일반390/320 각14개 상태를 새로 실행했다. 검색/지역/4조건/2테마/0건/저장/상세/날짜·시간/인원·동물/필수조건 오류/요약·이전/닫기·재진입/완료·내역·취소/지속저장/별도 맹견요청을 포함한다. 실제 매장에 전송하거나 결제하지 않는 로컬 체험 문구를 확인했다.
- `verify-accessibility-p5.cjs`: 각 폭의 200% 및 고대비8개 상태를 새로 실행했다. 긴 폼의 스크롤·최종 확인, 키보드 초점/Tab/Escape 복귀, hover 진입·해제와 동일 박스, reduced-motion을 검사했다. 실제 기기/Safari 검증으로 확대하지 않는다.
- `verify-p5-review.cjs`: 3매장 fullwidth x0/폭390·320, 사진·시간 x20, 인접표면 경계, 필터0/1/2, 저장2→1 순서별 교대면, 회색행 예약/상세/Escape 복귀, 확대/고대비와 태그 구조를 검사했다. 날짜7개44px/마감disabled와접근이름/시각보조행없음을 확인했다. 인원·동물은 실제 숫자 키 입력과 Enter로2→3/1→2가 바뀌고 요약3명·2마리 및 이전 초안에 반영된다. 프로그램 `selectOption` 검사와 구별한다.
- [키보드 한계](evidence/review-p5/native-keyboard-scope.json): headed/headless·touch 여부와 여러 방향키/열기 조합에서 OS 팝업의 확정값 변경은 확인하지 못했다. 이 경로는 미검증으로 남긴다. 성공한 숫자 typeahead도 모든 OS 팝업 조작의 검증으로 확대하지 않는다.
- [코드 검산](evidence/review-p5/code-checks.txt): 최종 토큰 정의/참조, 공식 SVG 경로, JS anti-slop Oxlint와 checkJs를 검사한다. 태그 글자 대비6.53:1. 정적 정보태그14px/아이콘16px/반경4px, 닫힌 select44·48px/아이콘20px은 목적별 토큰이다.
- [보드](evidence/p5-board-checks.json): 부모가1100/390/320에서 5개 원본·결과 비교와 실제 iframe 필터, 각 프롬프트 disclosure의 키보드 열기·닫기, 이미지/가로넘침을 실행했다. reviewer도 Q1–Q5 비교 캡처와 전체목록을 직접 읽었다.

현재 이미지와 행동은 P5에서 새로 생성·판독했다. P4 `final-checks.json`의 시간600/선택 청색·흰색/모션0·40·100·200ms/초점박스는 변경하지 않은 해당 역할의 상세 보간 증거로만 재사용한다. P5에서 입력/태그/매장 표면의 새 시각 증거를 해시 갱신으로 대체하지 않는다. fullPage 스크린샷 속 고정 탭은 캡처 시점 viewport에 붙어 있으므로 실제 스크롤 캡처를 함께 읽었다.

## 게이트 범위

catalog v4 활성75개의 원래 checks를 유지하고 프로젝트10개를 추가한다. 미적용6개는 사이드바/다열대시보드/채팅이 없는 범위이며 수행하지 못한 검사를 미적용으로 바꾸지 않는다. 17개 예외는 모바일 상시시간/관례적 아이콘 전용 조작/참조 그림색/수직탭 간격 등 기존 구체 범위를 보존한다. P5 정보태그는 사용자 R3형 정보표현 요구에 한정하며 상태마다 임의색을 추가하는 근거가 아니다. 게이트 CLI는 증거 무결성을 검사하고 실제 시각 판독은 이 문서와 캡처에 별도로 남긴다.

실제 예약 API, 실제 매장 정책·가격, OS 팝업 방향키 경로, 실물폰/Safari, 사용자 최종 품질 승인은 검증 완료 범위에 포함하지 않는다.
