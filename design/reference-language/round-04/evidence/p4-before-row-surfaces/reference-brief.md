# 라운드4 · 조사와 요소 분해

## 범위와 전환

사용자는 라운드3을 “괜찮네”라고 평가하고, 다음은 아이디어에 맞게 레퍼런스를 조합·각색했을 때의 화면 품질을 보자고 요청했다. 목표는 반려동물과 갈 수 있는 카페 탐색, 테마, 메인 퀵메뉴(동반입장·음료맛집·맹견전용), 예약을 가진 모바일 앱이다. 이전 픽셀 재현 평가를 그대로 적용하지 않고 제품 판단과 원본 장점의 유지/각색을 함께 평가한다.

## 제품 아이디어의 가설과 비용

동반공간·크기·이동가방조건을목록에노출하면방문불가카페를상세진입전에거를수있다는가설이다. 실제사용성연구결과로주장하지않는다. 정보가길어첫카페의시간이버튼이화면밖으로밀리면문구축소보다정보그룹/섹션밀도를재검토한다.

동반입장/음료맛집/맹견전용은동일한배타적분류체계가아닌빠른컬렉션이다. 동반입장은실내입장으로범위를명시하고,맹견전용은대형견일반과동일시하지않는다. 예시매장의정책은실제법규/안전보장이아니다. 사용자의단어를유지하면서상세에서적용조건을확인한다. 예약체험도실제접수로오해하지않게행동직전과완료상태에표시한다.
