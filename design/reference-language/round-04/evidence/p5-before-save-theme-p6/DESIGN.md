# 반려동물 카페 · 라운드4 디자인 기준

## Overview

보호자가반려동물과갈수있는카페를조건/테마로찾고동반조건을확인한뒤예약과정을체험하는모바일프로토타입이다. [조사·분해·Q-ID 결합](reference-brief.md), [구현 전 고정 P1](prompt-v1.md)을읽는다. 이번은제품각색평가이며원본미공개단일복제실험이아니다.

## Colors / Typography

현재 기준은 [스타일 관계 분석](style-analysis.md)과 구현 전 [P4](prompt-v4.md)다. 흰 중립 바탕, 먹색 정보, 청색 실행 조작으로 사진과 행동의 대비를 시험한다. 검색은 연회색, 선택/예약은 청색과 흰 글자, 카테고리는 대상별 채움과 색을 사용한다. 이는 원본 HEX 복사가 아닌 역할 관계의 각색이다. 이전 크림/초록안은 사용자에게 거절됐으며 스냅샷에 보존한다. 시스템한국어sans-serif,주제목22/섹션·매장이름·본문18/라벨14 CSS px. 실행중관리원본은 [app.css](app.css)의역할토큰이며이값들은chosen이다.

## Layout / Components

390×844를주비교조건,320을좁은폭으로검증한다. 좌우20px공통컨테이너,섹션36px/제목아래12px/카페간32px를선택한다. E1검색지역→E2조건퀵메뉴→E3두열테마→E4사진/동반조건/시간목록, E5상세/예약시트, E6하단3탭. 상세와예약도같은입력/버튼/정보위계를공유한다. 큰화면에서도모바일최대430px를보존한다.

## Shapes / Depth / Motion

사진8px,검색8px,보조버튼8px,작은선택pill로역할을구별한다. 카드전체에선/그림자를덧붙이지않는다. 시트는독립표면이고배경을가리며키보드포커스를관리한다. hover색150ms진입/해제,레이아웃크기불변focus,reduced-motion/forced-colors를확인한다. 하단nav는64px와safearea를한번만예약한다. 구분바/밑줄은없다.

## Do / Avoid / Unknown

카테고리·테마·매장입장조건·예약시간이실제로필터/상세/선택으로연결돼야한다. 네비게이션이빈버튼이거나API부재를이유로로컬동작까지빼지않는다. 사진은분위기예시이고4개카페/조건/음료가격/예약재고는가상데이터다. 로고·슬로건·가짜리뷰·즉시실제예약성공표현을만들지않는다. 맹견전용과대형견일반을혼동하지않는다. 실제운영정책/요금/입장조건/API·실물폰은미검증이다.

첫화면비교와최종행동·시각판독은 [review.md](review.md)에기록한다. 원본의일부색·요소존재만으로완료판정하지않고Q-ID별장점의유지/각색과전체밀도를검토한다.

거절 전 이력: 첫비교후 [P2](prompt-v2.md)에서비필수반경/색/글자단계를정리했다. 퀵슬롯은같은중립면,선택만초록;카페사진간격12px. 둘째테마사진은얼굴식별성을확인해crop을조정한다.

제품후속기준은 [P3](prompt-v3.md)에연결한다. 명시된목록일시를새로선택하는행동과상세초안을이어가는행동을구별하고,예약요청/체험결과문구와초점복귀를동기화한다.

P2의 동일 중립 퀵메뉴 결정은 전체 스타일 손실을 키웠다. P4에서 이 선택을 교정하며 원본의 풍부한 그림 표현을 공식 SVG의 채움/선/색으로 각색한다. 테마 사진144px로 탐색 비중을 키운다. 실제 검증 결과와 남은 차이는 review.md에 기록한다.


## P5 · 사용자 후속 교정

[P5](prompt-v5.md)는 카페 단위 구분, 아이콘 조건 태그, 셀렉트 외형, 상태별 날짜 치수를 다룬다. 목록 article을 흰색/중립 회색으로 번갈아 표시하고 상하16px로 각 매장에 여유를 소유시킨다. 인접 내용 간32px와 좌우20px 정렬은 유지한다. 사진·조건·해당 매장의 예약시간이 같은 표면 안에 속한다.

입장 공간/크기는 읽기 전용 아이콘 태그, 이동가방·실내 불가·사전 확인은 별도 설명으로 구별한다. 태그의 낮은 대비 청색은 정보이며 선택/예약 CTA와 다르다. 이 태그 스타일은 R3의 정보 배지를 각색한 값이다. 셀렉트는 공통 중립 필드/공식 화살표/focus를 적용하며 옵션은 네이티브 동작이다. 마감 날짜는 disabled와 접근성 이름으로 전달하고 시각적 보조행을 없애 기본/선택 날짜와 같은 높이를 유지한다. 확대에서 본문 자체의 자연스러운 증가를 금지하지 않는다.

P4의 간격만으로 충분하다는 내부 판단은 사용자 후속 교정으로 범위를 수정한다. 이전 결과를 이번 변경의 품질 승인으로 확대하지 않는다.

태그 추가 후 사진112px와 정보128px의 하단 불일치를 사용자가 지적했다. 사진은 최소112px에서 정보행 높이를 채우도록 조정하고104px폭/12px간격을 유지한다. 12px 조정 전에는 기본390에서사진·정보128px일치를확인했다. 현재는최소112px에서내용높이를함께따르며좁은폭/확대의증가를허용한다. 사진crop은해당사용처에서재검토한다.

사용자가 공간이 좁은 특별한 보조정보에12px를 허용하도록 기존14px절대하한을 변경했다. 현재 목록 조건태그/추가조건요약만12px/16px줄높이이며전용토큰/선택자를쓴다. 이름·가격·시간·입력·날짜·CTA·상세와확인조건은14px이상이다. 이 제한적예외는RUI-09 계약에연결한다. 같은조건은상세/예약에서큰글자로보존한다.

예약시간은72px기본폭의한줄가로목록이며스크롤바를숨기고다음시간을일부노출한다. 목록과예약시트에같이적용하며시간6개는가상예시다. 확대시숫자가버튼폭을자연스럽게늘릴수있다. 사진은정보행최소112px/실제높이를채우는관계를유지한다.
