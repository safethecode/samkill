# P12 · 예약 내역의 대상·기간·수량

사용자는 취소 대상이 모호하고 색이 맞지 않으며 주 제목/그룹 제목과 취소 상태가 중복된다고 지적했다. 그레이50 수준의 밝은 배경, 건수,1/3/12개월 조회도 요구했다.

예약 내역 주 제목 하나 아래 조회기간/건수/실제 방문일 범위를 둔다. 기간은 현재 달을 포함한1·3·12개 달로 정의하고 시작/종료 날짜를 직접 보여준다. 현재 달의 미래 방문도 포함한다. 항목은 방문일 최신순이고 상태는 각 카드에 한 번만 표시한다. 예약/취소 그룹 제목은 제거한다.
