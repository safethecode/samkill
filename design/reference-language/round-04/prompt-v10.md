# P10 · 저장 화면에 누적 피드백 적용

사용자는 예약 화면에도 위계/구분이 부족하다고 지적한 뒤 현재 작업 대상을 저장 화면으로 지정했다. 예약 화면 재구성은 후속 미완료로 남긴다.

저장의 핵심은 관심 카페를 다시 찾고 비교하는 일이다. 저장/저장한 카페 중복 제목을 하나의 주 제목으로 통합하고 저장 수만 보조로 둔다. 날짜와 각 카드의 강한 예약 시간 나열은 이 화면에서 빼고 사진/이름으로 상세에 들어가 예약한다. 카페 소개와 하나의 동반 조건 묶음, 지역 식별, 매장별 교대 표면과20px 정렬, 저장 하트 상태를 유지한다. 제목 아래 수량과 목록 사이20px로 위계를 구별한다. 빈 저장은0곳 메타를 반복하지 않고 남은 콘텐츠 영역의 중앙에 안내/둘러보기 버튼을 묶는다. 카드 크기를 고정하거나 글자를 줄이지 않는다. P9 클릭/키보드 초점 정책도 적용한다.
