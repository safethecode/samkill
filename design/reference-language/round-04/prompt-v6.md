# P6 · 저장 하트의 활성 표시와 테마 호버 제거

2026-09-10 사용자 교정: 좋아요를 눌러도 활성화되지 않는다. 테마로 둘러보기에는 불필요한 호버가 들어갔다.

구현 전 재현에서 저장값 green/aria-pressed=true는 반영됐지만 SVG fill은none,색은기본먹색이었다. 저장 기능과 별개로 실제 활성 표현을 놓친 실패다.

E4 저장 버튼만 save-toggle 범위로 지정한다. 기본은빈하트,저장은기존accent의채운하트와낮은대비선택면,해제는빈하트로돌아간다. hover중에도활성모양/색을유지한다. 크기·사진/정보정렬은바꾸지않는다. aria-pressed와localStorage/저장목록도동기화한다. 고대비에서도채움/윤곽의차이를확인한다.

E3 테마는공통button:hover배경을받지않고hover진입/해제표현을제거한다. 키보드focus-visible과클릭후테마필터는유지한다. 다른버튼의hover나모든키보드초점을함께제거하지않는다.

390/320에서누름/hover/해제/키보드/재로드/저장탭동기화,테마hover전후동일표현과focus/필터동작을실행한다. 저장데이터나ARIA검사만으로아이콘활성화완료라하지않는다.

## 추가 입력 · 카페 선택 정보의 위계

작업 중 사용자는 제목의성수와카드지역이중복되고메뉴가격은앱목적에불필요하며,실내동반불가등태그/설명을매번해석해야한다고지적했다. 후속변경전에기록한다.

목록은 이름 → 입장가능공간 → 동반조건 순서로읽는다. 같은지역으로한정된홈목록에서는카드지역을빼고전체지역/저장처럼제목에지역맥락이없는경우만지역을남긴다. 목록메뉴가격은제거하며대관비/방문조건확인등상세의중요조건을삭제하지않는다.

입장공간은14px의주정보태그+공식house/trees/paw로표시한다. 마당동반+실내불가는 `마당만 동반`으로합쳐가능범위를명확히한다. 그다음명시된 `동반 조건` 제목아래12px보조태그묶음에크기/준비물/추가확인조건을모은다. 태그만불쑥배치하거나태그와별도자유문구의의미를사용자가추측하게하지않는다. 조건예: 실내→10kg이하/이동가방필수,마당만→크기제한없음,맹견전용→단독이용/입장조건사전확인. 같은사실을중복하지않고모든필수조건은상세/예약확인에서도보존한다.

사진/정보공유행하단을유지하고390/320/확대에서새로운줄수·잘림을확인한다. 지역혼합/저장/필터,원래하트·테마동작과예약진입에미친영향을검사한다.

## 재교정 · 소개와 동반 조건의 의미 구분

2026-09-10 사용자는 실내/마당 여부 역시 동반 조건이며, 별도 상위 태그로 나눈 중간안을 거절했다. 위 추가 입력은 실패한 해석으로 보존한다. 이번 구현은 이름 → 어떤 카페인지 짧은 소개 → 하나의 동반 조건 묶음으로 수정한다. 공간/크기/준비물을 같은 묶음에 넣는다. 소개는 가상 매장의 샘플 문구이고 14px 본문으로 표시한다. 짧은 조건 태그에만 기존 12px 예외를 적용한다. 중복 지역명과 목록 메뉴 가격 제거는 유지한다.

검증 후 국소 보완: 320px 기본 화면에서 첫 예약 시간 하단6px가 고정 탭에 가려졌다. 소개·조건·글자 크기는 유지하고 목록 날짜 아래 여백만 기존12px에서4px 토큰으로 줄여 첫 진입 전체를 노출한다. 섹션 사이36px와 매장 사이 간격은 유지한다.
