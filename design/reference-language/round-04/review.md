## 사용자 교정으로 이전 결합 판정 철회 · 2026-09-10

사용자는 P1–P3 결과의 컬러·배치·느낌이 레퍼런스와 동떨어졌고 익숙한 색 선택과 불명확한 영역 구분이 남았다고 지적했다. 이어 원본 HEX를 복사하라는 뜻이 아니라 색을 선택하는 관점, 역할과 관계가 필요하다고 교정했다. 원본 제작자의 의도를 추측해 사실로 쓰지 않는다.

위의 Q1–Q4 adapted-and-verified는 부분적인 기능·배치 관계만 확인한 판정이었다. 그것을 전체 스타일·조합 품질까지 검증한 것으로 확대한 판단을 철회한다. 특히 F5에서 같은 중립색으로 퀵메뉴를 통일하면 핵심 장점이 유지된다고 판단한 것이 그림의 풍부함과 영역별 비중 손실을 키웠다. 기존 문장을 소급 삭제하지 않고 이 후속 기록으로 RUI-16/17 및 PROJECT-REFERENCE-SYNTHESIS를 user-confirmed FAIL로 남긴다. 기능 회귀 성공은 시각 결합 실패를 상쇄하지 않는다.

거절 상태는 [실패 스냅샷](evidence/user-rejected-p3/snapshot.json)과 [후속 실패 판독](evidence/user-rejected-p3/rejection-review.md)에 보존했다. app3개·당시 DESIGN·P1–P3·reference-brief·sources·독립 렌더/DOM/행동 증거를 포함하며 새 P4로 덮어쓰지 않는다. 200% 시간 숫자 분리와 forced-colors의 mask 아이콘 소실도 당시 미수정 결함으로 보존한다. 당시 최종 디자인게이트 PASS는 출력하지 않았다.

[P4](prompt-v4.md)는 사용자 교정 뒤 고정한 새 입력이다. 흰 중립면과 먹색 정보, 청색 실행의 대비·그림 표현·사진의 탐색 비중·매장 사이 쉼을 다시 검토한다. 이후 판독은 새 실제 화면과 행동에 한정하며 사용자 품질 승인으로 확대하지 않는다.

## P5 사용자 교정과 P4 판정 범위 정정

사용자는 P4 전체 개선은 긍정적으로 평가하면서 각 카페가 구분되지 않는다고 지적했다. 따라서 위 P4의 ‘매장 사이 쉼만으로 구별된다’는 RUI-25 판독은 충분하지 않았다. 이 부분을 사용자 확인 FAIL로 누적하며 P4 전체 개선을 부정하거나 사용자 최종 승인으로 확대하지 않는다. P4의 앱·계약·결과·증거는 `evidence/p4-before-row-surfaces/`에 보존했다. 주요 10개 파일은 커밋 `5b026fa`와 byte 일치하며 [baseline-audit](evidence/p4-before-row-surfaces/baseline-audit.json)와 별도 커밋 사본으로 확인했다.

[P5](prompt-v5.md)는 매장별 교대 표면을 먼저 고정했고, 작업 중 사용자 요구로 조건 태그/아이콘, 닫힌 select 외형, 마감 날짜의 보조문구 제거를 순차 추가했다. 모든 추가 요구가 최초 입력에 있었다고 기록하지 않는다. 교대면은 이번 목록의 소속 관계를 위한 선택이며 보편적인 필수 패턴이 아니다. R3의 짧은 정보 배지 역할을 입장조건으로 각색하되 원본 제작자의 실제 의도나 원본에 교대 배경이 있다는 주장은 하지 않는다.

## P6 사용자 교정 · 저장 활성과 테마 hover

사용자는 좋아요활성이보이지않고테마의hover가불필요하다고지적했다. 이전P5에서저장값/aria-pressed/저장목록동작을확인했어도실제하트채움/색을충분히판독하지못했다. 해당시각상태판정을철회하고사용자FAIL을누적한다. P5커밋0612dd1의앱/기준/게이트11파일은 `evidence/p5-before-save-theme-p6/`에git show로정확히보존했다. P6는저장버튼의빈/채운하트·선택면을직접검사하고테마hover제거와초점/필터보존을구별한다.

P6 정보계층의첫중간안은사용자가거절했다. 실내/마당도같은동반조건인데별도상위태그로분리한제품해석이잘못됐다. 해당중간안의기능검사PASS를제품품질PASS로확대하지않으며정보계층판정을철회한다. 소스/당시검증/캡처는 `evidence/p6-rejected-information/`에보존했다. 다음수정은이름→짧은카페소개→단일동반조건묶음이며같은지역정책과기존저장/테마검증은별도로유지한다.
