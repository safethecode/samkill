# 라운드4 · 색을 선택하는 관점과 스타일 관계

사용자 교정: 첫 각색은 레퍼런스의 배치·느낌·스타일을 옮기지 못했다. 색 커스텀은 필요하며 원본 색의 복사를 요구한 것이 아니다. 아래 O는 실제 이미지의 관찰, H는 그 효과에 대한 해석, D는 이번 제품의 선택이다. 원본 제작자의 실제 의도를 확인한 기록은 아니다.

## 관찰에서 결정으로

| 관계 | O · 이미지 근거 | H · 관찰 효과의 해석 | D · 이번 각색 |
|---|---|---|---|
| 색 면적과 주목도 | R1은 흰 면/회색 검색 위에 큰 붉은 배너가 있고, 아래 퀵메뉴 그림마다 색이 다르다. R2는 작은 시간 사각형이 강한 주황색이다 | 넓은 탐색 이미지와 작은 실행 조작이 서로 다른 크기로 시선을 잡는다 | 광고를 만들어 넣지 않고 테마 사진의 면적을 늘린다. 검색은 중립, 예약 시간에 청색을 집중한다 |
| 명도 대비 | R2·R3의 제목은 검정에 가깝고 부가정보는 밝은 회색이다 | 이름/제목을 먼저 읽고 가격·조건을 뒤이어 판단하기 쉽다 | 주 글자 #202124, 부가정보 #676b73. 가독성 하한을 지키면서 단계 차이를 남긴다 |
| 색온도와 콘텐츠 | R3 사진은 다양한 채도와 색을 가지며 외부 UI는 흰 면/검정 정보/작은 핑크 할인표시다 | 사진의 분위기를 UI 전체에 동일하게 입히지 않아 콘텐츠와 조작이 구별된다 | 사진의 녹색·우드색을 전체 배경/글자로 확장하지 않는다. 따뜻한 사진과 구별되는 청색 #245eea를 실행색으로 시험한다 |
| 그림과 조작 표현 | R1 카테고리는 공통 라벨 정렬 속에서도 대상별 색·채움·실루엣을 가진 그림이다 | 공통 슬롯이 정돈을, 그림 차이가 탐색의 풍부함을 만든다 | 기존 동일 베이지 원/작은 단색 선을 제거한다. 공식 Lucide의 채움/선/대상별 색으로 4개 카테고리를 구별한다. 원본 일러스트와 완전히 같지는 않다 |
| 간격과 소속 | R2 매장 내부의 사진/정보/시간이 가깝고 다음 매장까지는 크게 벌어진다 | 시간이 특정 매장의 끝에 속하고 다음 매장은 새 단위로 읽힌다 | 내부12px/매장간32px, 테마와 목록 사이36px. 금지된 구분선을 사용하지 않는다 |
| 선택과 확인 | R5는 선택 날짜·인원·시간에서 같은 주황/흰 조합이 반복된다 | 현재 선택과 다음 실행의 문법이 연결된다 | 선택 날짜/시간과 최종 CTA의 청색/흰 조합을 공유한다. 필터와 탭은 낮은 대비로 두어 예약 실행과 경쟁을 줄인다 |

색 면적/채도/명도는 이 단계에서 상대적 관찰이다. 정확한 픽셀 분포나 원본 CSS 값으로 보고하지 않는다. 선택한 HEX와 간격은 구현 전 [P4](prompt-v4.md)에 고정했다. 청색이나 위 숫자를 다른 제품의 보편값으로 옮기지 않는다.

## 거절된 결과와 판독의 실패

P1은 식물/우드 사진에서 따뜻한 배경·초록 글자/선택색을 골랐다. P2는 퀵메뉴 색까지 중립화했다. 그 결과 검색·그림 바탕·시간 버튼이 비슷한 베이지색이 되었고, 사진·제목·주 행동 사이의 대비와 섹션 차이가 줄었다. 기능 소속과 첫 시간의 화면 내 노출만 확인한 리뷰는 이 전역 차이를 놓쳤다. 사용자 거절이 우선하며 이전의 부분 `adapted-and-verified`를 전체 스타일 승인으로 사용할 수 없다.

뒤이어 에이전트가 “원본 주황색을 복구”하자고 설명한 것 역시 잘못된 축소였다. 색이름을 맞추는 것과 색의 역할·관계를 옮기는 것은 서로 다른 평가다. 이전 결과는 [거절 스냅샷](evidence/user-rejected-p3/rejection-review.md)에 보존한다.

## 수정 결과에서 볼 것

전체 화면을 먼저 나란히 놓고 검색→카테고리/테마→매장/예약의 비중과 시선 이동을 본다. 그다음 같은 표시 폭에서 그림의 실제 크기와 채움, 제목과 사진의 거리, 매장 내부/사이 간격, 선택/미선택을 확인한다. 선택값을 적었다는 사실이나 색을 바꾼 사실은 증거가 아니다. 실제 렌더의 판독은 [리뷰](review.md)에 후속 기록하며 사용자 품질 승인은 별도로 남긴다.

## P5 · 묶음 구분과 상태 표현의 후속 교정

사용자는 P4를 긍정적으로 평가하면서도 매장 간 구분이 부족하다고 지적했다. 간격이 충분하다는 내부 판독을 사용자 체감의 근거로 대체할 수 없다. P5에서는 사진/정보/시간을 같은 표면으로 묶고 흰색·기존 중립 회색을 교대한다. 원본 R2의 소속 관계를 제품 요구로 강화한 선택이며 원본에 교대 배경이 있었다고 주장하지 않는다.

R3의 짧은 정보 태그를 사용자 요청에 따라 입장 공간/크기에 적용했다. 연한 청색 태그+의미별 공식 아이콘은 읽기 전용 정보, 강한 청색 시간은 행동으로 구별한다. 이동가방·실내 불가·입장조건 사전 확인을 삭제하지 않는다. 셀렉트는 닫힌 필드의 중립면/화살표/focus를 통일하고 네이티브 옵션 범위를 공개한다. 마감 날짜는 보조줄 대신 disabled와 접근성 이름으로 표현해 다른 날짜와 같은 치수를 유지한다. 상세 입력/수정 이유는 [P5](prompt-v5.md)에 있다.
