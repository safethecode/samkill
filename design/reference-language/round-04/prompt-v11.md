# P11 · 예약 화면의 정보 위계

예약 내역은 주 제목 아래 체험임을 한 번 알리고 예약한 내역/취소한 내역을 분리한다. 매장 제목·지역, 일시·인원, 동반 조건, 해당 예약의 취소 행동 순서로 읽는다. 흰/회색 교대표면과 섹션 간격으로 경계를 만들며 구분선/탭 밑줄은 쓰지 않는다. 빈 예약은 남은 화면 중앙에 안내/둘러보기로 표시한다.

예약 일시 선택도 날짜/시간, 방문 인원, 동반 조건/동의를 서로 다른 묶음으로 구성한다. 요약은 항목별 라벨/값 간격을 구별한다. 날짜 disabled 크기 유지, 짧은 시간 가로 스크롤/바 숨김, 셀렉트 외형/상태, 입력초안/조건 동의/이전/닫기/완료/취소/저장 기능을 보존한다. 실제 예약으로 오해하지 않도록 체험 안내를 유지한다.

사용자 추가 교정: 저장처럼 내용이 화면에 들어가면 스크롤 없는 것이 기본이다. 양폭/높이별 scrollHeight를 확인하고 필요한 때만 문서가 자연 증가하도록 한다. 강제 overflow:hidden으로 긴 내용을 자르지 않는다. 저장의 여분 하단32px를20px로 정리하고 비필수 탄성 이동을 억제한다. 390×844의0/1/3항목은실제scrollHeight844였다.320×740의3항목은내용이넘쳐스크롤이필요하다.
