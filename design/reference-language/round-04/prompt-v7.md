# P7 · 목록 제목 묶음과 카드의 간격

2026-09-10 사용자는 목록 제목·날짜 바로 아래 카드가 붙어 위계가 구분되지 않는다고 지적했다. P6에서 첫 예약 버튼을 첫 화면 안에 맞추려고 날짜 아래 여백을4px로 줄인 결정이 원인이다.

제목과 날짜는4px로 한 묶음을 유지하고, 날짜 아래 첫 카드까지20px의 기존 inset 간격을 적용한다. 카드 내부·매장 사이·다른 섹션 간격은 유지한다. 좁은 화면에서 첫 시간 일부가 접히더라도 자연스러운 세로 스크롤로 접근하며 제목과 목록의 의미 관계를 압축하지 않는다. 고정 탭이 마지막 콘텐츠 접근을 막는 실제 가림과 첫 화면 경계를 넘는 정상 흐름은 구별하고, 스크롤/키보드로 시간 전체에 접근해 예약할 수 있는지 확인한다.
