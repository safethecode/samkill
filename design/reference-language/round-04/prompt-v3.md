# P3 · 제품 행동의 후속 교정 지시 기록

P1/P2와달리이문서는구현중메시지로전달한교정지시를검증후한곳에모은기록이다. 최초부터고정해넘긴프롬프트라고부르지않는다. 관련발견·지시·실제결과는리뷰/검증JSON에도보존한다. 사용자지적이아닌내부판독이다.

## 예약 재진입의 날짜 맥락

목록시간버튼은명시된9월12일을가리킨다. 이전에상세에서14일을고른초안이남았더라도목록의9월12일13시버튼을누르면12일13시를선택해야한다. 반면상세의 `예약 일시 선택`은특정날짜/시간을새로명시한행동이아니므로이전초안을이어간다. 클릭의실제대상과맥락이초안재사용보다우선하는경우를구별한다.

이전time-only함수는코드판독에서발견됐다. 수정전앱의행동캡처를이미보유한것처럼쓰지않는다. 별도브라우저에서이전함수를복원한고립재현이14일유지실패를보였고,현재코드를새로읽은후12일로전환됨을확인했다. 상세초안보존도별도로실행했다.

## 상태와 문구

맹견전용은예약요청체험이다. `요청 체험 완료` 뒤제목도 `요청 체험을 마쳤어요`로연결해실행행동과결과를맞춘다. 실제접수없음문구는유지한다. 저장탭에서는홈의조건chip이남지않고저장된카페전체를표시한다. 홈의필터/검색/지역/스크롤은탭복귀때보존한다.

## 원본 관계와 실제 소재

메인테마뿐아니라상세의dog사진도얼굴전체가보이는crop으로조정한다. 같은소재라도박스비율이다르면실제피사체잘림을각사용처에서확인한다. 사진의slot규격이나object-position변수존재만으로통과시키지않는다.

## 초점과 모션

초기화·필터·탭전환·상세뒤로·모달닫기·체험완료처럼DOM을다시그리는행동은키보드초점이사용자의다음작업으로돌아가야한다. 초기화는검색,상세뒤로는해당카페,예약내역보기는선택된예약탭으로연결한다. hover진입/해제의실제중간색변화와focus전후박스불변을검증한다. 웹킷기본검색clear와커스텀clear가중복되면후자를유지해하나의삭제행동으로정리한다.

실제후속검증은evidence/followup-results.json,date-regression-results.json 및독립리뷰자료에남긴다. 특정날짜/초점목적지를모든제품의보편규칙으로만들지않는다.
