# P4 · 메뉴 칸과 그림의 시각 크기 분리

원본을 보는 내부 비교에서 E4 둘째 행이 약9px 위에 있고 일부 그림이 원본보다 커졌음을 확인했다. P1이 모든 그림을36×36 contain으로 지정해 같은 슬롯과 같은 그림 크기를 혼동했다. 이는 원본을 못 본 구현 담당의 관찰 실패가 아니라 입력의 단순화 문제다.

## E4

4열/전체높이192와 첫 행 위치는 유지한다. 위18 + 첫 행74 + 행 간격16 + 둘째 행74 + 아래10 =192로 바꾼다. 기존 간격8/아래18을 각각16/10으로 변경한다. 두번째 슬롯 top은 패널 기준108px이다. 좁은폭에서 긴 라벨의 자연높이 규칙은 유지한다.

각 셀의 그림 **배치 슬롯**은36×36이며, 그 안의 그림은 원본 crop에390/1125를 곱한 표시 크기에 가깝게 따로 둔다. 슬롯 안 가로/세로 중앙, 이후 label gap10px은 동일하다. 이미지 자체의 크기가 라벨 위치를 바꾸지 않게 한다.

|그림|선택 CSS width×height|
|---|---|
|welcome|37.44×35.36|
|attendance|30.51×31.89|
|emotion|29.12×29.81|
|battle|37.09×36.4|
|quiz|25.65×31.2|
|lottery|30.85×32.93|
|roulette|30.85×34.67|

이 수치는 실제 crop 박스의 표시 배율이지 원본 CSS나 그림 잉크 경계의 실측이 아니다. 그림에는 원본 crop에 포함된 내부 여백이 남아 있다. 더보기의36px표면/18pxSVG는 유지한다. E5 flag crop도 같은 표시비율로 width61.71/height59.97을 선택해 원본의 시각 크기를 보완한다. 기존 오른쪽 예약공간62px에 들어간다.

P3 역할 토큰 방식과 ul/li/time 의미 구조를 유지한다. ui.css와screen/components에 같은 markup/클래스를 사용하고 독립표본도 동일한 박스를 검증한다. 최초~P3 입력/렌더는 보존하며 P4와 수정 이유를 보드에서 볼 수 있게 연결한다. 원본 미공개 상태를 유지한다.
