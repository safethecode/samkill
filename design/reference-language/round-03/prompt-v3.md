# P3 · 확정된 시각값의 토큰 사용 연결

P2의 현재 렌더와 마크업을 보존한다. 독립 리뷰에서 RUI-02 실패를 발견했다. P1은 역할 변수의 정의→참조→사용을 요구했지만 일부 색/그림자와 크기·간격이 CSS 직접값으로 남고 미사용 변수도 있었다.

ui.css의 앱 역할에 해당하는 색·글자·간격·반경·크기·그림자·투명도와 모션/포커스 값은 의미 있는 역할 변수로 정의하고 실제 선언에서 참조한다. nav글자 #191e24, 선택면 #eaf0f5, FAB/nav 그림자를 포함한다. 미사용 --nav-safe-area/--gap은 실제 역할이 없으면 제거한다. 원본 앱의 공식 토큰이라는 주장은 하지 않는다.

0/100%/auto/none, flex/grid 배분, 선택자/순서, source aspect ratio 같은 구조값까지 의미 없는 변수로 치환하지 않는다. @container/@media 경계는 CSS 변수 사용 제약이 있는 구조 조건으로 직접값 예외를 명시한다. 독립 보드의 설명 스타일은 앱과 별도 보드 역할 변수로 관리한다.

문구·수치·레이아웃·표본 대응은 바꾸지 않는다. 변경 전후390/320 렌더를 다시 캡처하고 PNG 픽셀 동일성을 확인한다. P2 소스/렌더는 보존한다. 이미 작성된 components.html P1 원문을 소급 고치지 말고 P3 링크를 바깥 설명에 추가한다. 최초 담당의 원본 미공개 상태도 유지한다.

반복 기록의 .record-list/.record는 ul/li, 날짜는 time datetime="2025-09-12"로 의미를 연결한다. 기본 list margin/padding/list-style을 명시적으로 reset하여 현재 시각을 유지한다. 스크린리더의 목록 구조만 보강하고 아직 없는 서비스 기능/링크를 만들지 않는다.
