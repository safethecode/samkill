# 닥터다이어리 메인 재현 실험 기준

## Overview

세 번째 원본→요소 언어→독립 구현 실험이다. [분석](analysis.md)과 [P1](prompt-v1.md)이 출처·관찰·선택·미확인을 구별한다. 앱 기능 개발이나 의료 서비스 출시 범위가 아니다. 앞선 두 사례의 수치/색을 이번에 복사하지 않는다.

## Colors & Typography

옅은 청회색 바탕, 흰 정보 표면, 네이비 주 글자, 회청 보조, 밝은 파랑 보상/추가, 청록 기록 표식은 이번 원본에서 선택했다. 실제 확정값은 [ui.css](ui.css)의 역할 변수다. 원본 서체는 미상이며 시스템 한국어 sans-serif를 사용한다. HTML 읽는 글자는14px 이상. 광고/고유 이미지의 내부 글자는 기존 크리에이티브 예외로 별도 기록한다.

## Layout & Components

390 CSS px 비교 프레임은 원본 y170–2436의 표시 조건이다. E1상단/E2광고/E3요약/E4바로가기/E5챌린지/E6기록/E7추가/E8탐색으로 분해한다. 기본 inset17px, 카드 내부 여백은 별도 역할이다. 독립 표본과 조립은 같은 CSS·마크업과 가용폭을 공유한다.320에서는 글자 축소 대신 필요한 자연높이를 허용한다.

## Shapes & Depth

원본의 큰 둥근 흰 패널, 요약과 탐색 캡슐, 원형FAB를 구별한다. FAB/탐색에 관찰된 그림자만 허용한다. 장식 구분 바와 탭 밑줄은 없다. E3 원본 세로선은 명시 기준에 따라 삭제한다.

## Do / Avoid / Unknown

8개 메뉴의 그림·라벨·행 리듬과 하단 요소의 가림 관계를 보존한다. 배너/브랜드 그림을 분리한 사실을 공개한다. 숨은 체중이나 새 메뉴/광고 문구를 만들지 않는다. 실제 앱 이동·기록 저장·광고 실행·safe-area는 미확인이다. UI 게이트는 정적 재현 범위이며 기능 완성을 뜻하지 않는다. [교정/검증](review.md)에 첫 렌더와 이후 변경을 보존한다.
