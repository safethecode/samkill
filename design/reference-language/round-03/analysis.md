# 3차 · 닥터다이어리 메인 분석

## 요청과 자료

사용자는 디맨드 실험을 “이번에도 잘했네”라고 평가하고 닥터다이어리 메인으로 후속 실험을 요청했다. 이전 승인은 디맨드 사례에 한정한다. 이번 입력은 UIbowl app_name=닥터다이어리, query=메인, MOBILE, page1/limit3의 유일한 결과에서 선택한 첫 이미지다. [출처·원본·crop 좌표](source.json), [전체 원본](assets/source.png)을 보존한다. 서명 토큰 URL은 기록하지 않았다.

원본1125×2436 image-px의 y170–2436을 비교 대상으로 선택했다. OS 시각/상태바는 제외한다. 390 CSS px 표시는390/1125배 선택이며 원본 DPR 추정이 아니다. 원본 이미지 안 날짜는2025년09월12일, 파일명은202607을 포함한다. 양자를 촬영 날짜로 단정하지 않는다. 조사/구현 날짜2026-09-10과 구별한다.

## 사용자 과제와 분해 이유

이번 사용자는 앱 이용자가 아니라 레퍼런스를 구현 언어로 번역하는 방법을 검토하는 사람이다. 핵심 행동은 대응 원본·프롬프트·구현을 비교하고 차이를 지적하는 일이다. 따라서 요소의 독립 표본과 전체 조립을 함께 제공한다. 서비스 관점에서는 홈에서 건강활동 진입점과 보상, 당일 기록을 확인하는 순서가 보인다. 실제 기록 추가·탐색 기능은 이미지에서 확인할 수 없다.

상세 사방 여백·치수·글자/아이콘 색·선/채움·상태·부모/형제와 조립 수치는 [고정 P1](prompt-v1.md)에 모았다. 모든 CSS 수치는 선택값, 원본의 눈으로 판독한 색/곡률은 추정값이다. 실제 소스 CSS 토큰을 확보한 것으로 부르지 않는다.

## 에셋과 코드 경계

광고는 카피·인물·제품·작은 고지문을 가진 하나의 기존 합성 크리에이티브다. 원본 그대로 분리한 bitmap 사용을 공개하며 광고 내용까지 언어로 새로 생성했다는 평가에 포함하지 않는다. welcome 등7개 고유 그림과 coin/shoe/flag도 crop했다. source.json의 image-px 좌표로 재현할 수 있다. 앱의 라벨·표면·배치·기록·내비게이션은 HTML/CSS다. 전체 화면을 이미지로 씌우지 않는다.

도구/내비게이션/더보기/추가 glyph는 Lucide 공식 저장소의 해당 이름 SVG를 내려받았다. 브랜드 삽화와 표준 glyph의 출처를 구별한다. 원본과 Lucide의 미세한 선/모양 차이는 허용 차이이며 원본 아이콘 라이브러리를 알아냈다고 주장하지 않는다.

## 사전 공개 차이와 미확인

- E3 중앙 세로선은 사용자 바 금지(RUI-14)에 따라 생략한다. 두 열의 관계는 남긴다.
- HTML 라벨14px 하한을 우선한다. 작은 원본 글자의 단순 비례 확대보다 커질 수 있다. 고유 이미지 안 글자는 원본 에셋에 한정된 예외이며 해당 글자의14px 충족을 주장하지 않는다.
- 첫 체중은 FAB에 가려 선행5만 보인다. 뒷숫자를 추정하지 않는다.
- 역사적 날짜/금액/라벨을 그대로 보존한다. 광고 주장·기록의 사실 여부를 검증하거나 새 건강 조언을 제공하는 작업이 아니다.
- 고정 탐색·FAB의 원본 실제 동작과 safe-area는 미상이다. 비교 프레임 상대 배치는 구현 선택이다.
- 320px에서 문구를 줄이지 않고 자연높이를 허용한다. 원본을 볼 수 있는 분석자와 P1/에셋만 받는 독립 구현 담당을 구별한다.

실제 결과·교정은 [리뷰](review.md)에 후속 기록한다. 사전 문서의 기대를 실행된 검증으로 바꾸어 읽지 않는다.
