# 독립 리뷰 사전 판독

검사자: doctor_review. source.png 실물(1125×2436)을 직접 보고 prompt-v1.md 전체와 대조했다. 원본 y170 이후를 390/1125로 비교하는 선택은 원본 CSS/DPR 복원이 아니다.

- E1: 홈/포인트/통계의 굵은 제목 행과 오른쪽 벨·달력. 원본의 비활성 명도가 보존되어야 한다.
- E2: 광고의 원본 크리에이티브 사용은 UI 문자·레이아웃 복원 능력과 분리한다. 작은 글자는 이미지 내부 예외로 공개해야 한다.
- E3: 원본 세로선을 사용자 금지로 생략한다. 두 수치와 아이콘의 가운데 정렬은 유지한다.
- E4: 4×2 삽화 메뉴의 여유와 라벨 질서가 핵심이다. 원본 삽화 재사용과 HTML/CSS 패널·격자 재현은 다른 증거다.
- E5: 원본 제목+참가자 pill은 한 줄, 보상설명은 아래, 깃발은 우측이다. 14px 하한 때문에 자연높이 증가를 P1이 허용했으나 겹침이나 과도한 빈공간으로 합리화하지 않는다.
- E6: 날짜와 요약보기, 3개 체중 기록을 확인한다. 첫 값은 가려진 5만 확실하므로 숫자를 추정하지 않는다.
- E7: FAB는 첫 기록 우측 하단에 걸쳐 있고 E8보다 위에 있다. 독립 표본에서 원형, 색, plus와 조립의 가림을 각각 본다.
- E8: 긴 capsule 안 5개 목적지, 건강만 제한된 옅은 면. 두번째/세번째 기록과 겹치는 정적 비교 관계이다. 실제 앱 탐색/고정 기능은 검증 범위가 아니다.

75개 active 원문을 모두 판독했다. 반경 >8px, 세부 4px 배수 이탈, 3개 이상 글자 크기, 원본 삽화 다색, 원본 그림자/광고의 장식, 아이콘 전용 도구에는 재현 작업의 구체 범위 예외가 필요하다. 구분 바와 HTML 14px 하한은 원본을 이유로 해제하지 않는다. 앱 실행/상태/채팅/폼/표/사이드바가 없는 규칙은 해당 부재를 개별 기록한다. 모든 적용 시각 판정은 구현 도착 후 실제 렌더에 근거해 작성하며 이 사전 문서는 PASS 증거가 아니다.
