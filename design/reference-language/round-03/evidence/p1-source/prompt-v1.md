# P1 · 닥터다이어리 메인 · 원본 미공개 구현 입력

## 범위와 공유 계약

정적 화면 재현 실험이다. 이 파일과 아래 지정 에셋만 보고 `screen.html`, `ui.css`, `components.html`을 구현한다. 원본/source-app 이미지나 다른 분석 자료는 열지 않는다. 광고/고유 삽화만 이미지이며 제목·포인트·메뉴 라벨·카드·기록·하단 탐색은 HTML/CSS다. 원본을 볼 수 없는 구현 담당의 독립 입력을 P1으로 고정한다.

관찰 O: 원본은1125×2436 image-px다. OS 상태바를 제외한 y170–2436을 비교한다. D: 비교 폭390 CSS px, 표시 배율390/1125를 선택한다. 실제 CSS/DPR·서체·스크롤 고정 동작은 미상이다. 아래 CSS 좌표는 이 비교용 선택이며 원본 CSS 실측이 아니다. 프레임은390×785.55px, 배경은 #f3f8fc에 가까운 옅은 청회색. 양옆 inset17px, 기본 흰 표면 반경22px, 주 글자 #20304f, 보조 #949cac, 메뉴 #58647e. 시스템 Apple SD Gothic Neo sans-serif. 읽는 HTML 글자는14px 이상, 주 정보16px/700, 메뉴14px/500. 원본 광고/고유 삽화에 포함된 작은 글자는 기존 이미지의 일부이며 HTML 14px 충족 주장 대상이 아니다. 별도 출처와 예외를 보드에 공개한다.

좌표는 app 프레임 왼쪽 위 기준. 390에서는 아래 y/h를 맞추되320에서는 긴 글자가 자연스럽게 늘어날 수 있다. 텍스트를 줄이거나 숨겨 폭을 맞추지 않는다. 독립 표본의 실제 내부 가용폭도390/320 조립과 같아야 한다. 설명 여백은 표본 밖 형제 요소가 소유한다. 공유 CSS 클래스와 동일 마크업으로 요소와 조립을 작성한다. 보드용 설명/프롬프트는 제품 UI 안에 넣지 않는다.

실제 이동/건강 기록/광고 실행은 관찰되지 않았다. 아이콘과 메뉴는 정적 상태를 `role=img` 또는 의미 있는 정적 목록으로 표시한다. 작동하지 않는 가짜 링크나 클릭 핸들러를 만들지 않는다. 전체UI 그림으로 덮지 않는다. 네이티브 details로 요소별 이 프롬프트를 보여줄 수 있다. 앱에는 구분선·탭 밑줄·영역 바를 추가하지 않는다.

## 조립 및 산출물

E1→E2(12px)→E3(13px)→E4(12px)→E5(20px)→E6, E7은E6 첫행에 겹침, E8은 둘째/셋째 기록 위에 겹침. 괄호 간격은 앞 요소 끝~다음 시작.390의 위 좌표가 목표이며14px 글자 때문에 E5/E6가 늘어나면 실제 변화량을 보고한다. 화면에 추가 여백/설명/버튼 없음.

screen.html은 순수 조립. components.html은 E1~E8 제목/프롬프트와 독립 실제 표본이며 공유 ui.css를 참조한다. 페이지 밖 body 폭을 줄이는 padding 금지. E6/7/8의 독립 표본은 대응 조립 markup을 같은 폭으로 보여주고 겹침 관계는 조립에서 검증한다. root CSS 변수로 색/간격/크기/반경/폰트 정의→참조→사용처를 연결한다. JS 필요 없음. 표준SVG는 제공된9개만 사용. source.png/source-app.png는 읽거나 구현에 사용하지 말 것.
