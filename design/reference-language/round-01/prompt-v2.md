# P2 — F1: 가려진 Day 3의 보이는 경계 보완

입력은 P1 전체 + 이 수정문이다. 원본을 다시 보고 작성한 분석 담당의 교정이며 사용자 지적은 아직 없다. P1과 screen-v1.png는 보존한다.

E4의 Day 3 설명을 다음으로 바꾼다. 나머지 요소와 좌표·간격은 유지한다.

> Day 3은 사진 조각뿐 아니라 장소 박스의 상단과 우측 경계도 보인다. 기존 관찰 조각 슬롯(x55, 폭311px, 표시 높이18px) 안에 사진과 장소 박스의 보이는 경계를 함께 재현한다. E4와 같은 경계색·두께·상단 반경을 사용한다. 전체 박스는 비교용 표본의 동일한96px 최소높이 규칙을 재사용하되 이는 구현 선택이지 가려진 원본 높이의 실측이 아니다. 슬롯 바깥 내용은 나타내지 않으며 하단에 새 경계선을 그리지 않는다. 가려진 이름·유형·상태는 생성하지 않는다.

검증: Day 3의 사진 오른쪽으로 얇은 카드 상단 경계가 이어지고 원본과 같은 폭을 차지하는지 확인한다. 제목·사진 조각·footer 좌표가 P1에서 바뀌지 않는지 확인한다. 전체 일정의 실제 스크롤이나 가려진 데이터를 복원했다고 주장하지 않는다.
