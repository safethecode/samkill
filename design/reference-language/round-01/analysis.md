## 공유 구조와 프롬프트

화면 → 제목/선택군/날짜그룹들/완료영역. 그룹 → 날짜제목/장소행들. 장소행 → 선택상자/장소박스. 장소박스 → 사진/텍스트묶음/순서표시. 독립 요소를 만드는 목적은 이 소속과 관계를 코드로 다시 표현할 수 있는지 확인하는 것이다.

각 요소의 사방 여유·글자·아이콘·색·상태·폭과 높이·짧은/긴 내용 및 조립 규칙은 [P1](prompt-v1.md)에 chosen CSS 값으로 구체화했다. 해당 CSS는 관찰 실측이 아니다. 원본의 시각적 거리를 특정 padding/margin이라고 단정하지 않는다.

원본 사진3개와 관찰된 조각을 그대로 에셋으로 제공했다. UI는 HTML/CSS로 구현했으며 전체 캡처를 구현 배경으로 쓰지 않았다. 공식 아이콘: [chevron-left](https://raw.githubusercontent.com/lucide-icons/lucide/main/icons/chevron-left.svg), [grip-vertical](https://raw.githubusercontent.com/lucide-icons/lucide/main/icons/grip-vertical.svg), 2026-09-10에 다운로드한 로컬 파일이 이번 재현 입력이다.

## 입력의 격리

prompt_implementation은 P1과 허용된 사진·SVG 에셋만 전달받고 screen/components/ui.css를 생성했다. 원본을 직접 보지 않았다고 보고했다. 부모가 최초 렌더를 보고 비교한 뒤 토큰화를 요청했고, 이후 별도 리뷰 작업에서 구현 담당에게 원본 접근을 허용했다. 그러므로 **최초 P1 구현만** 원본을 보지 않은 재현이다. 후속 P2와 리뷰를 같은 독립 조건의 새 표본이라고 주장하지 않는다.
