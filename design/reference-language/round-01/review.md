# 첫 비교와 교정 기록

상태: **사용자 교정 대기 중인 재현 실험**. 실제 브라우저에 표시한 HTML/CSS를 원본과 비교했다. 원래 앱의 CSS·동작을 복원하거나 제품 전체를 완성했다는 뜻은 아니다.

## F1 — 보이는 경계를 누락한 번역

- 지적 주체: 내부 비교. 아직 사용자 지적 없음.
- 대상: R1/P1/E4 Day3 관찰 조각.
- 원본 기대: 사진뿐 아니라 오른쪽으로 이어지는 장소 박스 상단 경계가 보임.
- 최초 실제: 사진만18px 조각으로 렌더되고 나머지 카드 경계가 없음.
- 원인: P1의 ‘사진만’ 지시가 원본 관찰을 축소했다. 구현 담당의 임의 누락이 아니다.
- 수정 입력: [P2](prompt-v2.md). 가려진 내용을 생성하지 않으면서 보이는 컨테이너 경계를 함께 복원.
- 보존: [P1](prompt-v1.md), [최초 렌더](evidence/screen-v1.png), evidence/v1-source의 최초3개 소스.
- 공통 해석 조건: 일부 가려진 요소에서 보이는 내용과 컨테이너 경계를 나눠 기록. 반례: 원본에 보이지 않는 경계는 추가하지 않음.

## 코드 보강과 실제 검사

ui.css의 디자인값을 의미/컴포넌트 변수로 연결했다. 구조값0/auto/비율과359px 미디어 조건은 직접값 예외다. 사진은 카드 외곽선 두께만큼 겹쳐 왼쪽 경계에 붙이며 이 음수값의 역할을 코드 주석으로 남겼다. 단순 위치 오차를 숨기는 보정으로 확대하지 않는다.

독립 리뷰에서 목록 의미 마크업과 조작 커서가 빠진 것을 발견해 보강했다. 원래 체크박스는 실제로 선택 가능하지만 날짜군/뒤로가기/순서/완료는 관찰용 표본이다. 프롬프트 입력에 이미 이 범위를 명시했다. 원본의 hidden 상태·전체 데이터·저장 조건을 확인하지 않았으므로 실제 여행 편집 서비스의 행동 완료로 보고하지 않는다.

표본의75개 활성 규칙과 코드/시각/키보드 등의 실제 결과는 [게이트 리뷰](gate-review.md) 및 gate-result.json을 참조한다. 비교 페이지는 제품 밖 검토 도구이며 별도 로컬 링크·원본/표본·프롬프트 펼치기 동작을 확인한다.
