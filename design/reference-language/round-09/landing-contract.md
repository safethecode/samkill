참조: 기존 refresh.cv 공개페이지의 짧은 가치 설명→문서 데모→구체 기능→시작 흐름, 서핏 공개페이지의 실제 화면으로 기능을 설명하는 방식을 재사용한다. 새 경쟁제품 조사나 미확인 성과 수치는 추가하지 않는다. 원본 이미지 references/refresh.png, surfit.png는 앞선 작업에서 직접 확인했다.

구현 전 ASCII:
  상단: 기존 서비스명 / 기능 소개 / 내 이력서
  첫 화면: 지원처별 작성 가치+시작 CTA / 실제 내용의 문서 예시

## 푸터 교정
사용자는 랜딩의 기본 구성인 푸터가 부실하다고 지적했다. 기존 한 줄 서비스명/링크에서 서비스 정체성·서비스 진입·사용 안내의 3열 구조로 보완한다. 앞선 공개 레퍼런스의 하단 정보 위계는 참고하되 미확정 회사 정보·약관·문의 주소를 만들지 않는다. 기존 토큰의 흰 표면, 제목16px/링크14px, 상하48px와 열간48px를 사용하며 모바일은 소개 다음 2열 메뉴, 320px에서는 1열로 흐르며 200% 글자도 잘림 없이 표시한다. 모든 링크는 실제 페이지/섹션으로 연결하고 별도 장식 구분선을 넣지 않는다.
