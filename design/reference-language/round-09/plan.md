# Round9 implementation plan

Goal: 이력서 작성·관리·지원용 복제·버전 복원·출력을 로컬에서 완주한다.
Architecture: classic scripts model.js / view.js / app.js와 CSS tokens. 직접 파일 열기 지원. localStorage 저장은 UI에 명시, 저장 실패를 성공으로 표시하지 않는다.
Spec: DESIGN.md 및 layout-ascii.md.

1. 목록의 첫 비교: 예시3문서 데이터, 필터·검색·문서 타일 구현. 1440 렌더를 R1과 같은 표시폭에서 비교하고 수정 후 편집 확장.
2. 편집/미리보기: 기본정보·소개·복수경력/학력·스킬, 새문서 생성·실시간 저장, 목록 복귀, 인쇄 CSS. 필드 변경이 저장/출력에 반영되는지 검증.
3. 관리/버전: 복제의 독립성, 보관/복원, 버전명·시점 저장 및 복원 전 안전 버전 보존, JSON백업.
4. 검증: file/HTTP 초기로드, 필터/빈검색, 생성·저장·재로드·복제·보관·버전·인쇄, 저장실패, 320/390/1024/1440 및 확대·키보드, lint/checkJs, 전체 catalog 규칙의 적용·근거 기록.
커밋·게시 없이 로컬 결과를 전달한다. 과거 사용자 수정 보존.
