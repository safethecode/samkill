# 구현 전 구조 비교

R1 관찰: 사이트 탐색 → 중립 배경[흰 목록면(제목/관리 → 문서타일+추가타일) → 첨부파일].
R2 관찰: 상단 문서도구 → 중립 작업면[좁은 도구 / 중앙 흰 종이(이름·연락처 → 소개 → 경력 → 학력)].

제품 목록:
  이력서                         새 이력서 +
  브라우저 저장 안내
  전체 / 작성중 / 작성완료 / 보관     검색
  문서미리보기    문서미리보기    문서미리보기
  제목·직무       제목·직무       제목·직무
  상태·수정일     상태·수정일     상태·수정일
  편집 복제 보관  편집 복제 보관  편집 복제 보관

제품 편집:
  목록으로 / 문서명          저장상태 / 버전저장 / 미리보기
  섹션목록   흰 문서[기본정보 → 소개 → 경력 → 학력 → 스킬]
             문서 전체 자연스크롤, 내용과 입력의 읽기순서 일치
제품 미리보기: 상단 돌아가기/인쇄/백업 + 같은 문서의 출력 내용.
제품 버전: 편집 위 대화상자, 시간과 버전명·복원. Esc/닫기 및 초점 복귀.
문자 선은 구현 구분선이 아니다. 좁은 폭은 목록1열, 편집 섹션 탐색은 접힘 없이 줄바꿈하는 짧은 도구목록. 문서 폭 넘침을 스크롤 숨김으로 막지 않는다.
