# 레퍼런스와 차별화 범위

- [점핏 이력서 목록](https://uibowl.io/website/%EC%A0%90%ED%95%8F?patterns=%EB%82%B4%EC%97%AD&patternName=%EC%9D%B4%EB%A0%A5%EC%84%9C): 직접 확인한 R1의 카드 중심 문서 관리. 목록의 흰 영역/중립 바탕/제목과 관리 행동을 채택. 공개 토글과 첨부파일 관리까지 구현했다고 주장하지 않는다.
- [원티드 편집](https://uibowl.io/website/%EC%9B%90%ED%8B%B0%EB%93%9C?patterns=%EC%83%9D%EC%84%B1%ED%95%98%EA%B8%B0&patternName=%EC%9D%B4%EB%A0%A5%EC%84%9C%20-%20%EC%86%8C%EA%B0%9C%2F%ED%95%99%EB%A0%A5%2F%EA%B2%BD%EB%A0%A5): 직접 확인한 R2/R3의 중앙 문서와 상단 도구. 원본의 낮은 대비/구분선은 사용자 기준에 맞춰 수정. 입력이 되는 부분을 명확히 표시한다.
- [서핏 공식 서비스 소개](https://www.surfit.io/intro/service): 깔끔한 이력서와 커리어 하이라이트, PDF/URL 공유를 소개. 공식 공개 페이지 이미지를 references/surfit.png에 확인. 로그인 뒤 편집기 실사용은 관찰하지 않았다.
- [refresh.cv 공식 페이지](https://refresh.cv/?lang=ko): 공개 데모에서 문서 편집과 지원 준비 도구를 함께 보여준다. AI 작성·공고 맞춤 기능은 공식 소개이며 우리 제품에 AI가 연결된 근거가 아니다. references/refresh.png. 제품은 과장된 점수 대신 입력·날짜 점검과 명시적 스킬 문자열 대조를 제공한다.

사용자 교정: 서비스 이름은 서핏(SURFIT). 단순 모방보다 UI/UX와 기능에서 나아야 한다는 목표. 비교한 제한된 공개화면만으로 경쟁 서비스보다 우수하다고 확정하지 않는다. 이번 실험의 검증 가능한 개선 가설은 지원처별 독립 복제, 변경 항목을 명시한 버전 비교, 복원 전 내용 보존, 로그인 없이 로컬 작성·백업이다. 실제 경쟁우위/채용성과는 사용자 비교실험이 필요하다.

최초 목록 캡처 전 편집기 코드도 이미 작성된 절차 누락이 있었다. 첫 화면을 비교한 다음 확장한다는 기준을 완전히 지켰다고 보고하지 않는다. evidence/first-list.png와 first-editor.png를 보존하고 이후 전체 결합을 별도로 대조한다.
