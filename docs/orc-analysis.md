## 디자인 방향

AI스러움은 생성 주체 판별 점수가 아니다. 이 패키지에서는 **사용자 과제·브랜드·관찰한 레퍼런스의 근거 없이 반복되는 장식과 구조**로 다룬다. 근거 없는 그라디언트, 모든 콘텐츠의 대형 카드화, 무지개 배지, 불필요한 KPI/히어로, 장식 애니메이션, 의미 없는 비대칭을 점검한다. 보라색·둥근 모서리·그라디언트 자체는 결함이 아니다.

## 범위와 완료 기준

5개 스킬: uibowl-research, reference-to-ui, reference-review, ux-copy, onboarding-flow.
각 스킬은 입력, 관찰 근거, 판단, 전달 결과, 중단/미검증 상태를 명시한다. 공통 패턴은 전달 문서의 evidence ID로 이어지며 필수 외부 스킬 의존성을 만들지 않는다. 추가 스킬용 템플릿과 회귀 평가 사례를 함께 제공한다.

## 한국어 UX 문구 추가 입력

사용자가 대화에 제공한 김자유(토스 UX Writer)의 「토스의 8가지 라이팅 원칙들」(2022-11-15) 본문을 기준으로 문구 지침을 보완한다. 최신 공식 정책이라고 주장하지 않으며, 댓글·메뉴·푸터·로고 표기는 원칙 자료에 포함하지 않는다. 명확함·간결함·친근함·존중·공감을 기반으로 8개 원칙을 한국어 점검 질문과 가상 UI 전후 예시로 바꾼다. 원문 전체를 패키지에 복제하지 않는다.

로컬 humanize-korean의 번역투/명사화/피동 관련 패턴도 참고했다. 이 요청은 기사 윤문이 아니라 제품 문구 스킬 제작이므로 장문 윤문 변경률·문장 리듬 강제·격식 무조건 보존 같은 규칙은 가져오지 않는다. 가능성과 불확실성을 나타내는 표현을 무조건 단정으로 바꾸는 규칙도 적용하지 않는다. 사실과 제품 동작을 먼저 보존하고 자연스럽게 고친다.
