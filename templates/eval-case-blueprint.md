# 행동 평가 작성 틀

아래 항목을 구체 과제로 작성한다. 이 파일 자체는 테스트 실행 결과가 아니다.

| 항목 | 작성할 내용 |
|---|---|
| 실제 사용자 요청 | 해야 할 작업과 시간/범위 제한 |
| 입력 자료 | 실제 이미지 또는 가상이라고 표시한 관찰, 출처, 알려진/미확인 값 |
| 허용 도구·부작용 | 읽을 파일, 사용할 연결, 쓸 임시 결과 경로 |
| 요구 결과물 | 실제 분석/명세/문구/검토 결과. 스킬 요약을 요구하지 않는다 |
| 채점 기준 | 관찰 가능한 결정, 근거 누락, 사용자 의도 보존; 평가자에게 정답으로 주입하지 않는다 |
| 반례 | 일반적인 금지가 틀리는 경우: 사용자 브랜드 그라디언트, 이미지 중심 카드 등 |
| 결손 사례 | 이미지 부재, 0건, API 결과 미상, 브라우저 접근 불가 |
| 결과 기록 | 실제 응답, pass/fail/not-tested, 문제 구절, 수정과 재실행 결과 |

## 실행 규칙

스킬 없는 기준과 스킬 적용 평가에 같은 입력을 준다. 별도 컨텍스트에서 실행하고 평가자는 기존 정답/실패 분석을 읽지 않는다. 결과를 읽고 수동 판정한다. 반복 평가를 했다면 횟수와 변동도 기록한다. 수행하지 않은 반복·이미지 관찰·실제품 검증을 수행했다고 쓰지 않는다.

새 실패가 생기면 해당 지침만 고치고 실패 사례를 다시 실행한다. 단일 통과로 모든 과제에서 효과가 보장된다고 주장하지 않는다.
